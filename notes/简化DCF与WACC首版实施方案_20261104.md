# 简化 DCF 与 WACC 首版实施方案

日期：2026-11-04。状态：首版已实施并完成科大讯飞实测验收，见[实施验收](DCF与WACC首版实施验收_20261104.md)。修订：显性预测复用现有三年，敏感性分析合并至 DCF估值 页。独立延长显性期的配置界面留作后续扩展。

目标：在当前相对估值模型上，复用收入与经营利润预测，以少量有依据的现金流比例和资本成本参数增加可解释、可调节、可复核的 FCFF DCF。首版采用比例法，不以完整历史现金流量表、完整经营营运资本明细或未来三表联动为前置条件。

## 1. 首版范围与产品决定

| 项目 | 首版决定 |
|---|---|
| 估值方法 | 保留现有 PE，新增 FCFF DCF；WACC 是 DCF 折现率模块 |
| 适用对象 | A/港/美非金融企业；银行、保险等先保留 PE/PB 等原方法，不自动套用此模型 |
| 经营预测 | 直接复用当前三个预测财年的收入、经营利润和费用率 |
| DCF 预测期 | 默认直接复用现有三个预测财年；仅在有研究依据且需要过渡时延长，不强制新增第4、5年 |
| 现金流方法 | D&A/收入、Capex/收入、ΔONWC/Δ收入三个比例；允许逐年设置 |
| 终值 | 永续增长法，单独计算显性期之后第一年的正常化 FCFF；三年预测时对应第4年，不要求额外做第4年完整经营预测 |
| 情景 | 首版为基准 DCF + WACC×g 敏感性；三种经营情景与反向 DCF 留作后续扩展 |
| 总结 | PE 与 DCF 并列，原 PE 继续作为主目标价；首版不自动加权两种价格 |
| 交付形态 | 原七张表 + WACC、DCF估值两张表，共九张；WACC×g敏感性放在DCF估值页下方，研究底稿增加DCF解释 |

FCFF 与 WACC 配对，FCFE 与股权成本配对。首版统一选 FCFF，避免现金流与折现率混用。[CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

## 2. 最少需要什么数据

“必需”指计算必须有有效数值或明确适用性判断，不代表每项必须来自财务接口。采用研究估计或人工假设时，标明依据、日期、单位和口径。

| 数据 | 取得方式 | 首版要求 |
|---|---|---|
| 历史基期收入、前三年预测收入 | 复用现有 facts 与分部收入预测 | 必需；计算第一年增量收入也需要基期收入 |
| 前三年经营 EBIT | 复用现有经营利润计算，增加必要调整 | 必需；明确是否含投资收益、非经营收益等 |
| 预测经营税率 | 现有税率假设，经正常化处理 | 必需；负会计税费不直接永久外推 |
| 三个现金流比例 | 历史、年报、研究报告、同业或人工研究假设 | 必需；不统一套用天孚通信的比例 |
| 延长预测期的收入增速与经营利润率 | 仅在主动延长显性期时新增 | 可选；首版三年方案不需要这组过渡假设 |
| Rf、Beta、ERP、Kd、税盾税率、D/E | 市场工具、计算或有来源的参数输入 | 必需；允许明确标记为估计 |
| 稳态 g、利润率、税率及再投资比例 | 研究假设 | 必需；与现金流币种及成熟状态相容 |
| 现金、有息债务、股数 | 最新可得资产负债表和行情，必要时手动补充 | 必需；记录各自日期，不把总负债当有息债务 |
| 非经营资产、非控股权益、优先股等 | 仅在适用时补充 | 确认不适用可显式置零；缺失不自动置零 |
| 历史 CFO、D&A、Capex | 进门公司财务查询；现有已实测可取 | 用于校准和交叉核验，不要求 CF 全科目齐全 |

现金加回要考虑受限资金与最低经营现金。若首版采用估计，单列调整并说明；不可默认为全部货币资金都能分配。有息债务至少核对短长借款、债券、到期部分和租赁，防止漏项或重复。少数股东权益若用账面值近似其价值，明确说明是近似。

数据缺口分为“有来源值”“采用估计”“缺少关键输入”。前两类可出值并展示依据；关键输入缺失时展示具体缺项，不生成伪精确 DCF，也不阻止原 PE 模型正常输出。

## 3. 三个现金流比例如何形成

| 比例 | 推荐校准 | 形成预测时的判断 |
|---|---|---|
| D&A / 收入 | 最近1—3个完整财年的 D&A/收入，查看均值/中位数和趋势 | 结合资产投用与折旧周期；不要求建立固定资产折旧附表 |
| Capex / 收入 | 最近1—3年、最新中期和已披露资本开支计划 | 扩产期可高、成熟期可回落；核对是否包括无形资产与资本化研发 |
| ΔONWC / Δ收入 | 有可比经营性营运资本时计算历史增量比值 | 缺少明细时采用可解释的研究或同业假设；历史收入变化很小、结构突变时不机械取比值 |

历史 CFO 用作现金转换能力的交叉核验，不作为必须逐年增长后直接折现的 FCFF。已有“流动资产−流动负债”不得直接当作 ONWC 校准值。比例法的目的，是明确估计未来经营性资金投入，而不是假装历史明细已经齐全。

每个假设保存：数值、适用年份、事实/估计/人工判断类别、来源标题或接口记录、来源日期、理由。人工判断可直接写理由，不强行制造不存在的外部引用。

三个比例可逐年不同。Capex 统一为正的现金投入，保留供应商原始符号。不得对所有返回值一律取绝对值；收入下降带来的合理营运资本释放也不强行截为零。

## 4. 计算链

### 4.1 三年预测与可选过渡期

前三年直接使用现有经营预测：

```text
经营EBIT = 原模型经营利润 − 不应纳入经营估值的收益 + 必要经营调整
NOPAT = 经营EBIT × (1 − 正常化经营税率)
D&A = 收入 × D&A比例
Capex = 收入 × Capex比例
ΔONWC = (本年收入 − 上年收入) × 增量营运资本投入比例
FCFF = NOPAT + D&A − Capex − ΔONWC
```

首版经营亏损默认不立即确认现金退税：简化税额采用 max(经营EBIT,0)×税率；已有可证明的抵扣或退税另行显式估计。亏损结转的逐年使用模型留作后续扩展。WACC 税盾税率与经营税率分别保存，不因字段名称相似而强行共用。

A 股可复用当前毛利减销售、管理、研发费用加经营净收益的链，但“其他经营净收益”需要核对。港美以营业利润为起点，扣除已辨认的非经营收益。原 PE 利润链保持原口径，DCF 的调整单独列示、可追溯，避免牵动现有 EPS。

首版显性期直接复用 facts.forecast_periods（当前为三个财年），不新增第4、5年详细预测。三年、五年都不是DCF的硬性要求；延长的作用是表达尚未结束的增长、利润率与再投资过渡，不是延长本身就使估值更准确。

三年方案把第4年及以后的现金流计入第三年末终值。若第三年仍处于高速增长或扩产期，单列稳态利润率、税率、Capex、D&A与营运资本投入假设，不直接沿用第三年的扩产期FCFF。若从第三年直接切换稳态缺少合理依据，再选择增加过渡期。

可选延长期只增加 DCF 所需的收入与经营利润率，不延长所有分部研究卡；其假设与原 PE 三年预测分开保存。估值结果明确显示显性期长度、末期收入增速和稳态假设。

### 4.2 WACC

```text
Ke = Rf + Beta × ERP
WACC = Ke × E/(D+E) + Kd × (1−T税盾) × D/(D+E)
```

| 参数 | 首版规则 |
|---|---|
| Rf | 优先调用进门新宏观入口，选择与现金流币种匹配的期限和名义利率；人工输入须有日期和依据 |
| Beta | 优先有定义的来源值；否则股票与基准收益率回归。建议默认两年周频，记录实际起止日、样本数、基准、复权、原始Beta及是否调整 |
| ERP | 独立研究假设或可追溯外部数据；不拿贷款风险溢价替代股权风险溢价 |
| Kd | 当前可融资利率/债券收益率优先；无可得数据时可用 Rf+明确的信用利差估计 |
| E | 全公司经济权益的市场价值，核对多类别股份与不同上市地价格 |
| D | 全口径有息债务，首版允许说明过的账面近似值；不使用总负债或负的净债务作为权重 |
| T税盾 | 依据可实现的利息抵扣与适用税率估计；不能无条件套历史会计有效税率 |

首版采用当前资本结构；若显式设目标结构，Beta 与杠杆调整必须一致。净现金公司债务权重可为零；不能产生负债务权重。

Kd 若按 Rf+信用利差估计，Excel 使用公式链接两项，不写成固定合计值。Beta 原始值、调整值、覆盖值分别存放；不将某个样本的 Beta 夹断区间当作全市场规则。

本轮进门实测发现 Rf 表格日期与序列元数据截止日存在冲突。实施时校验证券身份、来源、日期、时区和单位，不能默认返回首行就是估值时点可用数据。

### 4.3 终值与股权价值

```text
n = 显性预测期年数（首版默认3）
稳态收入 = 第n年收入 × (1+g)
稳态经营EBIT = 稳态收入 × 稳态经营利润率
稳态D&A、Capex = 稳态收入 × 各自稳态比例
稳态ΔONWC = (稳态收入 − 第n年收入) × 稳态增量投入比例
正常化FCFF = 稳态NOPAT + 稳态D&A − 稳态Capex − 稳态ΔONWC
终值 = 正常化FCFF / (WACC−g)
经营价值 = 显性期FCFF现值 + 终值现值
归母股权价值 = 经营价值 + 可加回现金 + 未计入经营价值的非经营资产
               − 有息债务 − 非控股权益价值 − 其他适用权益索取权
```

WACC 必须大于 g。g 不直接沿用高速增长阶段的收入增速；不把“g<Rf”作为所有市场通用的机械限制。终值中的利润与再投资单独正常化，不直接把扩产期最后一年 FCFF 乘 1+g。三年方案的正常化FCFF为第4年辅助计算列，用来代表永续期第一年的现金流，不是新增一套第4年分部研究。终值位于第3年末，按该期末至估值日的期限折现。增长与再投资关系可用稳态再投资率、隐含资本回报交叉检查，无需首版先补完整历史 ROIC。[Damodaran：终值与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)

租赁采用一致口径：若将租赁作为融资，EBIT、D&A、未来租赁再投资、债务扣减相互匹配；缺少精细附表时允许有依据的简化估计并说明，不能只加回使用权折旧却忽略未来租赁投入。资本化研发已包含于 Capex 时不重复扣除；非经营资产对应收益已在 FCFF 中保留时不重复加回资产价值。

金额按项目统一单位计算。现项目金额常为“亿”、股数为“百万股”，每股值需要相应乘100；再复用现有报表币种到交易币种和 ADS 转换规则，避免重复换算。

### 4.4 估值日

估值日与行情快照日期一致，按实际财年截止日计算各期折现期限，不能把港美财年默认成自然年。

财年已开始时，只估值剩余期间现金流。优先使用已实现 FCFF 或更细经营信息；首版缺少这些数据时，允许用全年 FCFF×剩余财年天数/全年天数估计，并明确“均匀发生”及季节性局限。折现按估值日至各财年末的实际剩余期限计算；终值折现到最后一期末。

现金和债务使用最新可得资产负债表，并标注日期；重要的期后融资、分红、回购等做显式调整。若估值日现金/债务只能估计，给出桥接假设，不能让全年已发生的现金流同时出现在首年折现与现金余额里。

## 5. 展示内容

| 工作表 | 核心内容 |
|---|---|
| WACC | Rf、原始/调整/采用Beta、ERP、Ke、Kd、税盾、资本结构、WACC；来源与日期 |
| DCF估值 | 上部：3年收入/经营EBIT/税/D&A/Capex/ΔONWC/FCFF及实际折现期限；中部：稳态年、终值、股权价值桥、每股值；下部：WACC×g价格敏感性矩阵，中心格等于基准DCF |
| 原总结页 | 原PE目标价、DCF价格、各自相对现价空间、WACC、g、终值占比、主要假设和估计项 |

敏感性不独立建sheet，与DCF计算放在同页，引用同一组输入和股权价值调整。默认 WACC 上下各1个百分点、0.5个百分点间隔，g 上下各0.5个百分点、0.25个百分点间隔，参数可配置。WACC≤g 的格子显示不适用。每个 g 都重算稳态ΔONWC与其他依赖g的再投资，不能只变终值分母。公式引用显性期实际长度和末期日期，不写死五年或折现指数5。

所有数值输出与参数直接联动。研究文字记录生成时点，是当次结果的解释；Excel 内手动修改参数后，数值汇总更新，研究叙述需重新生成。明确这一边界，避免显示静态分析文字已经同步更新。

## 6. 最小工程改造

首版集中新增 `valuation/dcf/`，不拆成多套大型流水线。复用已有取数、市场标识、汇率、文件读写和样式规则。

建议新增两个持久化文件：

| 文件 | 内容 |
|---|---|
| dcf_inputs.json | 启用状态、估值日、财年、显性期配置、少量历史校准、经营调整、现金流比例、可选过渡/稳态假设、WACC输入、股权价值调整及逐项来源 |
| dcf_results.json | WACC、逐年FCFF、折现期限、终值、股权价值、每股结果、敏感性、输入指纹及计算版本 |

最小改动位置：

| 位置 | 变更 |
|---|---|
| 新增 dcf/ | 定向补取、假设整理、经营口径桥、过渡期、WACC/DCF/敏感性计算及规范校验 |
| research_dossier/snapshot.py 等经营计算 | 提取可复用的经营预测计算，供 DCF 与原研究快照共用，避免复制出不同利润数字 |
| pipeline.py、shared/state.py | 在 research_dossier 之前增加 DCF 阶段；支持启用开关、续跑和单独重算 |
| workbook/load_json.py | 按启用方法读取 DCF 输入；旧 PE 任务缺少 DCF 文件时保持兼容 |
| workbook/build.py、anchors.py、styles.py | 增加WACC、DCF估值两张表和总结行，敏感性位于DCF估值页下方，所有关键结果用公式引用 |
| workbook/certify.py | 增加 DCF 身份、期间、单位、勾稽、敏感性和联动校验 |
| research_dossier/snapshot.py、schema.py、analyst_agent.py | 增加 DCF 结果及假设解释，保持 PE 为首版主目标价，说明方法分歧 |

建议流程：现有历史财务/分部/成本/同业阶段 → DCF少量补取与假设 → 共用经营计算及DCF结果 → 研究底稿 → 编表 → 验收。

DCF 补取单独保存，不把完整现金流需求加入原 PE 核心字段门槛。两个市场的同名字段不无条件合并；按公司、证券代码、报表币种、财年和来源确认映射。

重建时根据输入指纹重算 DCF 结果，不能复用与新假设不符的旧价格。JSON 为持久化输入；Excel 内修改可即时查看该文件的结果，再次由程序生成时仍以已保存输入为准。若需要把 Excel 调整回写到项目，另做明确的导入流程。

## 7. 实施顺序与验收

1. **打通计算。** 复用现有三年利润预测，以显式假设跑通三年 FCFF、WACC、第三年末终值与每股价值。先用科大讯飞验证负税费正常化，再用可核验的小型数值样例独立对算。
2. **补少量取数。** 对接 D&A、Capex、CFO 校准、现金债务和市场参数；接口不覆盖的字段允许有来源的研究假设。增加港美财年、币种、多类别股份和 ADS 校验。
3. **完成交付。** 增加WACC和DCF估值两张表、总结和底稿解释，将敏感性合并在DCF估值页；补齐参数联动、重建与原PE兼容验收。

通过标准：

- 不收齐 CF 全表也能通过有效假设得到基准 DCF；假设与历史事实明确区分。
- 前三年 DCF 收入和调整前经营利润与原模型逐年一致；调整项目单列。
- 默认仅复用原三年预测；可选延长显性期时，末期引用、稳态年、折现期限与敏感性同步变化，不残留写死的第5年引用。
- 修改任一年 Capex 比例、D&A 比例、营运资本比例或经营税率，FCFF、DCF、敏感性中心和总结数值随之更新。
- 修改 Rf 时，采用 Rf+信用利差口径的 Kd、Ke、WACC及DCF一并更新。
- 敏感性中心格与基准价格一致；WACC≤g 不生成有效终值；g变化时稳态再投资同步变化。
- 股权价值桥、亿/百万股、汇率与 ADS 的独立复算一致；不同财年及剩余期间计算正确。
- 缺少关键输入显示具体原因，不当零、不沿用旧值；不影响未启用 DCF 的旧 PE 任务。
- 数值计算与 Excel 公式以同一口径独立对照；研究底稿和当次生成的表格一致。
- 不采用静态情景价格参与动态总结；不声称静态研究文字会随 Excel 参数自动改写。
