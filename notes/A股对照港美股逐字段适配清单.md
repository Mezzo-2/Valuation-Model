> 本文保留完整 A 股字段对照作为研究记录。最新提数范围以[港美股财务数据需求清单](港美股财务数据需求清单.md)为准；不要求港美股补齐全部 A 股科目，数据获取与底稿是否展示分开处理。

2026-10-21。范围为当前估值模型第一步历史财务数据，以及计算历史比率、预测 EPS 和比较目标价所需的基础口径。EPS 只保留基本 EPS，不把稀释 EPS 纳入本轮需求。

## 判定口径

- **有年报值、接口缺返**：补取主表或附注中的原数，不靠估算补齐。
- **有年报值、接口口径有差异**：按原年报口径校正，原接口值保留为交叉验证信息。
- **年报可能合并披露**：先查附注；有独立金额可展示，但必须记录与合计项的包含关系。只有确认同期间、同口径时才可拆分。
- **年报未单独量化 / 不适用**：保留缺失和原因，不因接口没返回就认定为零或未披露。
- **模型派生 / 外部数据**：不要求年报直接提供模型自定义科目或当前行情。
- **待核对**：尚未逐家公司核对完整年报及附注，不能声称年报没有。下表“有返回”表示覆盖，不表示已逐项核实准确性；“本轮未返”也不等于供应商永远不能提供。

| 营业外支出 | 不一定存在 A 股同名分类 | 当前未取到可直接复用的目标字段 | 与营业外收入同样处理；不能把所有一次性项目都当作非经营项目 |

| 历史加权平均股本_百万股 | 多个样本年报 EPS 附注中有基本加权平均股数 | 两市场接口均未取得目标值 | 作为基本 EPS 核验和备查项；直接拿到基本 EPS 时不设为历史展示的强制前置项；不得用当前股本替代 |

|---|---|---|

| 流动负债合计 | 样本有 | 两市场均有返回 | 对照报告范围，不与短期借款混用 |
| 长期借款 | 年报可有银行借款、债券、融资租赁等不同项目 | 港股本轮未返目标项；美股扩查可返长期债务，但不等于长期借款 | 保留原始债务分类；约定“长期有息债务”可聚合已确认分项，不直接改标签 |
| 非流动负债合计 | 已确认泡泡玛特、小米等年报披露 | 港股未返，美股可返 | 港股从年报补；同口径时也可用总负债减流动负债派生，不是年报缺失 |

| 归母股东权益 | 样本有；单一股东归属结构时可能只列股东权益 | 两市场均有返回 | 核对是否为归母而非全部权益；有明确归属关系时才作差额推导 |
| 少数股东权益 | 有非控股权益的样本年报披露；无此结构的公司可能不适用 | 港股未返；美股部分返回，阿里还存在夹层权益归类差异 | 从原报表取非控股权益；不把夹层权益一起塞入；未返回不能视为 0 |
| 股东权益合计 | 样本有 | 两市场均有返回，但阿里两地接口对夹层权益的处理不同 | 按年报普通权益总额定义并另列夹层权益；不要为了凑平资产而扩张权益范围 |
| 负债和股东权益总计 | 年报有总额，但标签可能是“负债、夹层权益及权益总计” | 当前港美映射未统一该行 | 取真实原报表总额；存在夹层权益时改用完整加总结构，不仅算负债加普通权益 |
| 营运资本 | 可能披露净流动资产；也可直接计算，未必有同名科目 | 两市场有返回，已通过流动资产减流动负债的 27 组检查 | 延续本模型“流动资产减流动负债”定义，不替换成经营性营运资本 |

额外适配字段：**夹层权益 / 可赎回非控股权益**。这不是年报没有，而是 A 股当前两项资产平衡结构未覆盖。阿里 FY2025 原报表单列夹层权益 117.13 亿元人民币；需使用“资产 = 负债 + 夹层权益 + 权益”的报告结构。不能把它无依据归入少数股东权益或普通股东权益。

## 行情字段：年报不提供当前时点数值

| 字段 | 为什么不从年报取 | 适配方式 |
|---|---|---|
| 当前股价 | 年报不是实时行情 | 行情接口取快照及报价币种 |
| 当前总股本_百万股 | 年报只能证明某个报告时点股数，可能已有回购、发行、转换 | 取对应快照股数，核实普通股/ADS 及股份类别；用于预测时明确股本假设 |
| 流通股本_百万股 | 当前自由流通范围不同于年报总发行股数 | 可选行情数据，不以总股本冒充 |
| 总市值_亿 | 当前市值依赖当前股价和证券单位 | 行情取值，或按同基础价格、股数计算；多股份类别不能无条件用某一类价格乘全公司股数 |
| 流通市值_亿 | 同上，且依赖自由流通定义 | 按行情口径提供，无法确认时留空 |
| PE_TTM | 依赖当前价格、滚动盈利及供应商口径 | 行情接口，标明亏损/无有效倍数，不能以历史某年基本 EPS 冒充 TTM |
| PB | 依赖当前股价和净资产口径 | 行情接口，可选校验；注意普通股/ADS 基础 |
| Beta | 市场统计量，依赖窗口与基准 | 当前模型可选；另取有定义的行情统计，不要求年报提供 |
| 快照日期 | 行情观察时间 | 随行情保存，用于股价、股数、汇率时点一致性检查 |

## 年报能证明的基础口径及需外部补充的口径

| 字段 | 来源及缺口 | 适配方式 |
|---|---|---|
| 财年标签 | 接口有，但必须与原年报列对应 | 财年与自然年分开保存，按真实年度列取值 |
| 财年起止日 | 年报可提供，结构化返回不一定完整 | 保存实际日期，识别 52/53 周财年，不硬设 12 月 31 日 |
| 财报发布日期 / 版本 | 年报、公告可提供，重述比较期可能更新 | 保留公告日期和来源版本，明确是否采用重述后的比较数 |
| 报表列报币种 | 年报说明及主表表头可证明；接口输出币种未必是原币种 | 以合并报表列报币种为主；功能货币、交易币种、便利换算列分开 |
| 金额倍率 | 年报表头、表格说明可提供 | 金额、EPS、股数各自识别单位；不能把表格金额倍率套给 EPS |
| 会计口径 | 年报可区分 GAAP/IFRS、报告/调整口径、合并/母公司等 | 主表报告口径为底层，不混入调整利润、非 GAAP 指标、IFRS 调节表或母公司单体数 |
| 费用包含关系 | 主表及附注可提供，但不一定能证明任意拆分 | 用原报表布局和包含标记；未证明时只展示不重复合计 |
| 基本 EPS 分子及每股基础 | EPS 附注可证明；不一定就是不经调整的归母净利润 | 优先直接用披露基本 EPS；如计算则核对普通股归属、优先股等调整及基本加权股数 |
| ADS 对普通股比例 | 年报、存托协议或发行人披露可提供 | 按证券及有效日期保存；每股与每 ADS 统一 |
| 当前行情股数的单位 | 年报能证明 ADS 比例，但不能自动证明行情供应商字段的股数单位 | 另核实供应商字段定义，不能仅据年报比例猜当前股数基础 |
| 交易币种 | 行情/证券资料 | 与列报币种独立保存 |
| 当前汇率 | 年报汇率是历史或便利换算汇率，不能充当当前比较汇率 | 财务和原币种估值先完成；与交易股价比较时再取有日期、方向、来源的汇率 |

## 模型计算项：不是年报缺失字段

| 字段 | 计算及限制 |
|---|---|
| 营业收入增速 | 同口径年度收入之比减一；首年无前期数则留空 |
| 毛利率 | 毛利 / 营业收入；零收入时留空 |
| 销售费用率 | 仅在有效布局中用销售费用 / 营业收入 |
| 管理费用率 | 仅在有效布局中用管理费用 / 营业收入；含研发与不含研发不能混比 |
| 研发费用率 | 有独立金额则可展示，但若属于管理费用其中项，费用总额不再重复扣 |
| SG&A 费用率 | 真正 SG&A / 营业收入，不能使用含研发而未说明的接口标签 |
| 有效税率 | 同口径所得税费用 / 税前利润；税前利润为零时留空，不换用营业利润作分母 |
| 少数股东比率 | 对应归属口径的少数股东损益 / 合并净利润；不将优先股或夹层分配混同 |
| 其他经营净收益 | 已核实营业利润 - 毛利 + 当前有效费用项合计；保留派生依据 |
| 非经营净收益 | 已核实税前利润 - 营业利润；保留派生依据 |

## 连年报也不能直接补出的情况，怎样适配

| 情况 | 真实含义 | 处理 |
|---|---|---|
| 某项目只有合计、全文也无可核对的独立金额 | 真正的独立披露缺口，例如部分公司无形资产、某些费用细分 | 独立字段显示 -，使用合计布局；不猜拆分、不强填 0 |
| 某公司根本不适用某科目 | 不是一般意义的数据缺失 | 有年报依据才记不适用；只有年报明确金额为零或关系足以证明为零时才填 0 |
| 港美没有 A 股同名科目 | 会计分类差异 | 改模型映射和利润桥，不造“税金及附加”“营业外收入”等同名值 |
| 模型残差、比率和加总字段 | 派生值而非原始披露 | 明确公式与输入来源，单独标为派生 |
| 当前行情、当前股数、当前汇率 | 时点不属于年报 | 行情或汇率来源补充，不用年末旧值冒充 |
| 未来收入、费用率、税率、股数假设、目标 PE | 预测和估值判断，不是历史事实 | 用研究、同业及明确假设形成，不能伪装成原报表清洗结果 |
| 本次检索片段没有 | 尚未取得，不证明年报没有 | 扩展检索、取完整表格/附注或读取原文；状态记待获取，不提前记未披露 |

不能给出一份对所有港美公司都成立的“年报没有的字段”名单；需要逐公司、逐年判断。对本模型来说，基本 EPS、税前利润、所得税、港股非流动负债、已披露研发、已披露存货属于应补取/校正的数据，不能因为当前接口不完整就删掉。

## 本次补查的重要事实更新

1. **腾讯研发不是年报没披露。** FY2025 附注披露研发开支约 857.47 亿元人民币。其与主表行政费用的包含关系仍须保留，不能另扣一次。此前“接口没有独立研发”不应解释为“年报没有研发金额”。
2. **苹果也不只是合并披露 SG&A。** FY2025 主表 SG&A 为 276.01 亿美元；附注 13 的分部信息还披露销售营销合计 195.24 亿美元、一般行政 80.77 亿美元。相加与主表 SG&A 一致，说明应先查附注，再判断是否无法拆分。按用户选择，底稿仍可统一使用真正 SG&A 加研发。
3. **阿里港股存货可补。** FY2025 资产附注明列存货 18,887 百万元人民币，即 188.87 亿元。接口港股未返，不是年报未披露。
4. **阿里夹层权益必须独立。** FY2025 年报夹层权益 117.13 亿元，非控股权益 685.35 亿元，两者不是同一科目；不能以资产平衡差额填入普通权益或少数股东权益。
5. **苹果固定资产标签需要校正。** FY2025 PP&E 净额为 498.34 亿美元，经营租赁使用权资产为 112.05 亿美元，合计正好对应接口“固定资产”610.39 亿美元。因此应先明确展示 PP&E 还是包含经营租赁使用权资产的更宽范围，而不是认定同名接口数就是原报表 PP&E。
6. **苹果无形资产暂保留缺失。** 本次完整 FY2025 10-K 及针对性资产附注检索中，未找到可直接填入“无形资产净额”的独立总额；不能由“其他非流动资产”倒猜，更不能记成零。这是对该报告的独立金额判断，不外推所有年份或公司。

## 落地顺序

先补年报表格/附注获取及确定性清洗，按公司、财年、列报币种、会计口径、原始科目保存事实；再将事实映射到有效费用布局和利润桥。每个缺失显示 -，备注区分待获取、未单独披露、不适用。每个派生值保留公式及输入来源。A 股原有运行路径保持不变。

原始报表事实和映射规则通过后，才将其用于历史费率、税率及 EPS 校验。只取基本 EPS；历史基本加权股数是核验项，预测股数另作明确假设。当前阶段不为完成 PE 模型而扩展整套现金流估值输入。
