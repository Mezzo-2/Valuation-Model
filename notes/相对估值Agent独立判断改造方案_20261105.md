# 相对估值 Agent 独立判断改造方案

日期：2026-11-05。状态：已按本方案实施；结果见[改造验收](相对估值模型PE改造验收_20261105.md)。

## 1. 本次调整范围

相对估值页在“核心池中位数”之后新增一行“模型给定PE”，展示估值 Agent 判断的合理 PE 和一至两句简要原因。

下方“综合估值预测”保留原有悲观／中性／乐观三行、PE调整系数／目标PE／目标价／较现价空间列，以及固定 ±15% 的情景规则。各情景目标 PE 改为引用新增的“模型给定PE”作为基础倍数。

同业池、同业均值与中位数继续展示。本次不增加同业分类列、不放宽现有核心池家数要求，也不让 Agent 分别制定三种情景 PE。

## 2. Excel 展示与公式

同业表之后的布局为：

| 项目（A列） | PE（B列） | 简要说明（新增行使用C至F列） |
|---|---|---|
| 核心池均值 | 原均值公式 | 沿用现有展示 |
| 核心池中位数 | 原中位数公式 | 沿用现有展示 |
| 模型给定PE | Agent 给定的数值，可调节输入 | 一至两句说明主要参照及本公司的合理定位 |

新增 PE 行使用现有倍数格式，原因使用本行右侧C至F列的空白区域并自动换行，避免窄备注列将新行撑得过高。港美股原有每股收益至交易价格换算行按现有规则展示。

综合估值预测保持现有结构：

| 情景 | PE调整系数 | 目标PE | 目标价 | 较现价空间 |
|---|---|---|---|---|
| 悲观 | 中性系数 × 0.85 | 模型给定PE × 本行系数 | 目标PE × 首年EPS × 换算系数 | 目标价 ÷ 现价 − 1 |
| 中性 | 默认 1，可调节 | 模型给定PE × 本行系数 | 目标PE × 首年EPS × 换算系数 | 目标价 ÷ 现价 − 1 |
| 乐观 | 中性系数 × 1.15 | 模型给定PE × 本行系数 | 目标PE × 首年EPS × 换算系数 | 目标价 ÷ 现价 − 1 |

新任务由 Agent 直接确定合理 PE，中性调整系数默认 1。Agent 不再通过另一个非 1 的 pe_adjust 重复表达同一项估值溢价或折价；原有系数作为可调节情景参数保留。

例如模型给定 PE 为 30 倍、中性系数为 1 时，悲观／中性／乐观目标 PE 分别为 25.5／30／34.5 倍。此数字仅说明公式，不代表对任何公司的估值结论。

汇总目标 PE 继续链接中性情景，合理价值区间继续链接悲观与乐观目标价，中枢目标价、空间和评级沿用原有规则。

## 3. Agent 增加的判断

保留现有提名和核心池筛选流程，在筛选 Agent 输出中增加“模型给定 PE”及原因，使该环节同时承担合理倍数的判断。判断需要说明：

1. 主要参考哪些同业、哪个年度的 PE，以及本公司相对这些参照的定位。
2. 明显高低倍数是否有材料支持的原因，是否适合用于本公司定价；可以保留在核心池并在已有备注或判断中解释局限。
3. 本公司的增长质量、盈利能力、商业模式、现金回报或风险差异，如何支持最后给定的 PE。

PE 比较应考虑增长、风险和股东可获得的现金回报。方法参考：[Aswath Damodaran：PE Ratios](https://pages.stern.nyu.edu/adamodar/New_Home_Page/lectures/pe.html)。具体字段与流程为针对当前项目的设计。

均值、中位数和样本分布由程序提供，帮助判断。Agent 可以选择接近这些统计值的 PE，但需要结合实际解释；不能默认“均值就是合理 PE”，也不能仅因数值偏高就认定样本高估。

新增行的简短说明需要交代主要参照和定位理由，避免“综合行业情况给予合理估值”等空泛表述。原因未确认时明确写出，不虚构高倍数的成因。详细判断和来源在研究底稿中展开。

## 4. 判断所需的输入

向估值 Agent 补充本公司已有分部研究和经营预测摘要，包括收入、利润、EPS、增速、利润率及重要风险。复用公共经营计算，不另写一套盈利预测。

复用已获取的同业财务快照，提取可用的增速、利润率、ROE、现金流和杠杆等信息，保留期间、单位和来源。区分历史、季度累计和预测值，不用历史增速冒充前瞻增长。

对重要参照或显著异常样本，复用现有检索及读取工具按需补查；建议初始预算最多四次检索、四次读取，材料足够时直接作判断，不要求对每家同业重新做完整估值。

经营摘要不能反向依赖包含估值结果的完整 snapshot 或 load_spec，避免同业阶段出现循环依赖。

## 5. 最小数据及代码改动

继续使用 comps_spec.json，保留现有 core、pe_adjust、rationale、open_gaps，新增：

| 字段 | 含义 |
|---|---|
| model_pe | Agent 给定的合理 PE，有限正数，对应本公司预测首年盈利口径 |
| model_pe_reason | 展示于新增行备注的一至两句简要理由 |

实际用于判断的来源和必要的详细说明仍需保存，可复用已有研究记录并按需补充。新任务 pe_adjust 以 1 初始化，保留用户按原模板自行调节的能力。

| 位置 | 调整 |
|---|---|
| peer_agent.py | 增加经营上下文、可用同业指标及按需研究能力，输出新增两项 |
| schema.py | 校验模型 PE 有效、理由非空，继续检查证券身份和明确的财年/盈利口径冲突 |
| fetch.py | 提取已获取快照中的可用经营指标，不重复拉取相同数据 |
| workbook/build.py | 插入一行，场景目标 PE 的基础引用从均值改为模型给定 PE |
| snapshot.py | 以 model_pe × pe_adjust 计算中性目标 PE，同业均值作为统计背景保留 |
| 研究底稿 Agent | 引用同一份 PE 及依据，修改原有要求解释“采用均值”的提示 |
| certify.py 及测试 | 校验新增输入、公式来源及跨表一致性 |

DCF继续独立交叉验证。EPS 预测、汇率及 ADS 换算、固定情景系数和评级门槛沿用现有规则。

## 6. 旧任务与验收

旧任务没有 model_pe 时，允许明确按历史均值模式复现，并在新增行注明沿用历史规则；不能把旧均值伪装成 Agent 已完成独立判断。获得新的判断需要重跑同业估值及后续快照、底稿和编表。新任务缺少新增字段时不得静默退回均值。

验收重点：

1. 新增且仅新增一行“模型给定PE”及简要说明，悲观／中性／乐观结构和 ±15% 规则保持一致。
2. 手动修改模型 PE 后，三种情景目标 PE、目标价、合理价值区间及总结页联动，核心池均值和中位数不受影响。
3. 漫步者保留业务可比的高倍数同业，但 460.72 倍等样本不再经均值公式自动决定目标价；实际给定 PE 要有依据，验收不预设数值。
4. 泡泡玛特和普通集中样本能给出针对公司的理由，不只是复述统计值。
5. Agent 输出、Excel 新增行、Python 快照和研究底稿的 PE 及目标价一致；A/港/美币种、股份换算和情景公式回归通过。
6. 旧任务可复现，新任务缺失模型 PE 或理由时明确失败；资料不足保留具体原因，不默认编造 PE。

本版取代此前让 Agent 分别给定三种情景 PE、增加同业分类列和放宽核心池家数的扩展设计。本次重点是新增一个有理由的基础 PE，并接入原有综合估值预测。
