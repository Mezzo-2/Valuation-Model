# 港美股估值模型改造计划

计划日期：2026-10-26；实施更新：2026-10-27。状态：代码改造及回归已完成，实际数据仍存在下列来源限制。

目标：按已确认的港美财务底稿，打通历史数据、经营假设、利润预测、基本 EPS 和 PE 估值。保留完整的盈利推导，按市场适配科目与连接方式。

本文采用最新约定：底稿不设口径批注列，必要差异直接体现在科目名称中。目标样式说明和本轮生成样例已同步更新；旧调查产物保留原状。

## 2026-10-27 版式修复补充

按用户最新要求，A/港/美改为共用 A 股现有七表版式。已移除港美独立工作簿布局；市场差异仅保留科目、名称及计算规则。历史底稿恢复利润表/资产负债表并排，总结恢复公司介绍和左右分栏，运营成本恢复成本毛利区及费用区，利润预测恢复同比等展示。此前四列纵向版式的实现已被本次修复替代。取数、预测假设和估值结果沿用。详见《统一A股建表模板修复验收_20261027》。

## 实施结果与剩余条件

- 港美历史解析、费用假设、完整利润链、普通股基本 EPS、币种与交易单位转换和七表工作簿已接入现有流程；A 股原取数分支保持原状。
- 少数股东损益按约定优先取独立值，其次用同口径合并净利润减归母净利润；名称不加“计算”。港股样本可补齐，美股当前通用归母字段的调整范围未确认，暂保留缺失，不能将全部利润差额视为少数股东损益。
- 同业 Forward PE 按 2026-10-27 实跑修复后的规则：保留供应商有效数值，定义或财年未返时记录局限，不冒称统一首年 PE；已明确冲突者排除。一致预期 EPS 仍须确认币种、调整范围和普通股单位。
- 当前接口部分证券没有明确币种、ADS 比例或报表/交易币种汇率。年报检索只辅助识别币种与证券单位，不增加通用财务补数引擎；仍缺信息时可出财务底稿，完整估值需补齐。
- 本轮验证包含五家公司实际测试接口响应、港美两套公式联动样例和 A 股历史黄金样本回归；公式样例不代表真实公司的投资预测。

以下保留改造范围和验收设计，实际结果以验收记录为准。

## 2. 第一阶段：先固定字段映射和利润关系

复用 2026-10-26 测试环境的响应和数据组说明，只对仍未明确的项目补充定向查询。每个实际使用的字段记录查询名称、返回名称、已知定义、单位、币种和对应财年，沿用已有日志。

| 核实项 | 已知情况及本阶段要完成的内容 |
|---|---|
| SOPR | 已选定营业利润口径；确认当前“营业利润”实际映射到该字段，不能改用税后 sinvc |
| Basic EPS / SBCOC | 已能英文召回；固定其扣非基本 EPS 定义，并识别普通股或 ADS 单位 |
| 税前利润、所得税 | sibt、stax 已返回；落实其与扣非利润主链的配套范围。文档已证明字段存在，尚不能仅据字段名认定全部关系成立 |
| 净利润、归母利润、普通股利润 | 确认各返回项的归属与调整范围，识别 SBCOC 对应的利润分子；不把含非经常性项目的 bincc 直接接入扣非主链 |
| 少数股东损益 | 现有港美扩展查询已包含“少数股东损益”“非控股权益应占利润”等别名，但存档未见独立返回；按用户最新约定，独立值未返回时用同口径合并净利润减归母净利润补齐，无须专门等待接口新增该字段。核对两项的币种、财年、调整范围和利润归属；美股使用扣非主链配套利润 |
| SG&A | 按数据组 COALESCE(SGAXRD, SSGU, SSGA) 规则核实实际返回范围；回退项的研发包含关系不凭名字推定 |
| 基本股数 | 检查能否独立取得基本加权平均股数、当前普通股股数及 ADS 比例，并确认单位 |
| 财年及币种 | 优先使用财年标识与实际截止日期；分别确认财报币种、接口金额币种和交易币种 |

交付：在现有记录中形成一张可直接用于实现的字段映射表，以及收入到 EPS 的历史关系核对结果。数据定义未明确的项目写出具体缺口，继续推进不依赖它的取数与底稿工作。

2026-10-26 补充离线复核：对当日已保存的测试环境响应计算，苹果 FY2025 的税前利润 1327.29 减所得税 212.05 等于接口净利润 1115.24，而接口归母净利润为 1120.10；微软 FY2025 的税前利润 1236.27 减所得税 217.95 等于接口归母净利润 1018.32，而接口净利润为 1024.99。金额均为各记录中的亿美元。原始数和算式保存在 `output/finance_test_recheck_20261026/profit_chain_arithmetic_recheck.json`，这次为存档复核，不是重新调用接口。

这些关系表明当前字段组合尚不能直接视为完整可勾稽的利润链；其原因可能涉及利润归属、调整范围或未返回的中间项目，算术差额本身不能判定供应商错误，也不能判定具体差额性质。第一阶段优先补齐并核对少数股东损益，再判断剩余差异是否涉及调整范围或其他项目。不能按某个利润项碰巧满足算式就动态选它，更不能先用未知差额生成预测调整项来掩盖尚未明确的映射。

## 3. 第二阶段：改历史取数和财务底稿

### 3.1 市场配置

在现有历史财务模块增加 A、港、美三套小型字段配置：查询词、必需字段、可选字段、展示顺序和名称。A 股继续使用原配置。

科目的内部标识与展示名称分开。改“基本每股收益（扣非）”这样的中文名称时，公式和研究输入仍通过固定字段关联；不新建另一套工作簿生成器。

### 3.2 取数与缺失

- 港股按销售成本、税前利润、所得税等已验证字段查询；美股增加 Basic EPS 和 SG&A 的明确映射。
- 港美取消必须按 A 股分类独立取得营业外收入、营业外支出等拆分的要求；少数股东损益优先取接口值，未返回则用同口径合并净利润减归母净利润补齐。若计算所需利润缺失则显示“—”，不自动按零处理。
- 可选历史值保持缺失，导出为“—”；真实零仍为零。缺一年不再删除其他年度已有值。
- 底稿出表与完整估值分别判断必需输入：缺少可选资产项目不影响出表；缺少真实估值必需输入时报告具体字段，不编造结果。
- 历史基本 EPS 直接取数，不再以“归母净利润÷EPS”作为所有港美公司的强制前提。

### 3.3 展示、财年与币种

- 港美每家公司沿用一张历史财务表，按利润表摘要、资产负债表摘要、历史指标排列，取消右侧口径批注列。
- 必要差异写进名称，如“营业利润（SOPR）”“基本每股收益（扣非）”；已确认范围更宽的资产使用准确的范围名称。
- 表头统一列明公司、市场、币种、金额单位、EPS 单位、来源和数据日期。每年保留实际截止日期。
- 最近三个年度按已披露完整财年选择；查询范围覆盖可能已经披露的当前财年，避免自然年规则遗漏。
- 优先沿用年报列报币种。若接口只有另一币种版本，按实际币种展示，不改标签或猜汇率倒算；完整模型的收入、费用、利润和 EPS 使用一致的金额基础。

本阶段验收：泡泡玛特和苹果可直接生成新财务底稿；缺少可选科目仍可出表，查询结果与原值一致。

## 4. 第三阶段：保留完整盈利预测链

### 4.1 主链

港股：分部收入 → 合并收入与毛利 → 适用费用 → 营业利润 → 税前利润 → 净利润 → 归属普通股股东的利润 → 基本每股收益。

美股：分部收入 → 合并收入与毛利 → SG&A、研发及适用经营项目 → 营业利润（SOPR）→ 同口径税前利润 → 同口径税后股东利润 → 基本每股收益（扣非）。

费用的范围和扣非调整按第一阶段的映射处理，不默认毛利减 SG&A、研发就一定等于 SOPR。

不把净利率法或独立 EPS 预测设为默认替代路径；本次优先完成上述盈利推导。

### 4.2 中间项目的连接

| 连接位置 | 处理方式 |
|---|---|
| 毛利及费用 → 营业利润 | 费用分清独立项与其中项；确有其他经营项目或扣非调整时按其范围连接 |
| 营业利润 → 税前利润 | 有适用独立项目时使用原项目；缺少拆分时允许采用范围明确的合并净调整假设 |
| 税前利润 → 净利润 | 使用与主链匹配的税费假设，保留税费或税收收益的方向 |
| 净利润 → 普通股股东利润 | 少数股东损益优先取接口值，未返回则按同口径合并净利润减归母净利润补齐；预测中按“归母净利润＝合并净利润－少数股东损益”连接，再处理实际适用的优先股等普通股归属项目。少数股东损益可以为负，保留原符号 |

其他合并衔接项仅在历史端点同币种、同财年且关系已确认时计算，其名称只描述实际连接作用，不把未知差额直接认定为某个会计科目。少数股东损益采用下述已约定的补齐规则。

少数股东损益补齐规则：接口值优先；缺少接口值时，按同一财年、币种、调整范围和适用利润归属的“合并净利润－归母净利润”计算。底稿名称统一为“少数股东损益”，不增加“计算”“测算”等后缀，也不为该项新增可见批注。计算依据沿用现有取数和处理记录，便于内部追溯。任一必需利润缺失时保留“—”；结果为负时正常保留。补齐主要解决合并净利润至归母净利润的连接，其他利润与 EPS 关系另行核验；回代相等属于算术检查，不能替代源字段定义的确认。

对报表口径与扣非口径之间的连接，必须先明确调整含义，不能将所有未知差额混成“其他经营收益”。测算项用于预测假设区；历史财务底稿保留原取得科目，不增加虚构的披露行。

未来合并衔接项由历史关系、适用经营因素和研究材料共同支持，可以有预测假设；不自动照搬历史残差，也不要求模型为公司未披露的细分科目补数。

### 4.3 费用和税费假设

- 港股假设采用适用的销售、管理、研发费用率；研发属于其中项时不重复进入费用总额。
- 美股新增 SG&A 费用率，保留适用研发费用率；取消必须分别填写销售和管理费用率的要求。
- 营业利润率及费用率按主链字段定义计算；不能用扣非营业利润与未经确认的利润行直接推导税率。
- 匹配口径确认前，历史税费比率仅作描述；不将其自动作为扣非利润预测税率。匹配确认后正常用于税费预测。
- 合法的亏损、税收收益及接近零的分母单独处理，不把历史有效税率机械限制为 0—100%。预测假设的合理性检查与历史原值展示分开。

### 4.4 EPS 和股数

- 历史基本股数优先独立取得；仅在利润分子确实与该基本 EPS 匹配、EPS 非零且股份单位一致时，才允许反推，并标为计算值。
- 预测 EPS 使用归属普通股的匹配利润和预测基本加权平均股数。美股两者沿用扣非定义。
- 第一版股数预测可采用明确的持平假设，以已核实的普通股股数为基础；存在有依据的回购、增发影响时再调整，不增加复杂股本预测子模型。
- 普通股 EPS 与每 ADS 收益只转换一次；历史加权股数和当前时点股数分开保存。
- EPS 为零或负值仍保留原数；不因无法反推股数而让整张财务底稿失败。
- 若完整 EPS 计算缺少必需数据，明确停在对应计算位置；不自动改用不同口径利润、不隐藏切换成独立 EPS 预测。

本阶段验收：调整收入、费用、衔接项、税费或股数假设时，后续利润与 EPS 按已定义关系变化；Excel 和研究摘要计算一致。

## 5. 第四阶段：接通一致预期、同业与目标价

- 本公司一致预期优先使用明确的 EPS 数据；由利润计算时，同样核对归属、扣非范围、股数和 ADS 单位。
- 比较我们的 EPS 与一致预期前，识别基本/摊薄、扣非/报表及财年范围。不把不可直接比较的差异写成预测偏离。
- 同业选择按目标公司的市场和业务调整现有指引，取消默认优先 A 股的固定顺序。
- 继续使用已有 Forward PE 来源，核对其对应盈利定义和预测期间；不能确认可比的先展示原值，不自动混入目标 PE 均值。
- 目标价仍为预测 EPS × 目标 PE；EPS 换为交易币种、对应每股或每 ADS 后再与股价比较。汇率方向和日期明确，避免重复换算。
- 经营预测可使用年报币种；港股目标价显示交易币种，美股按其交易币种显示。研究文案同步更改固定的“元”“亿元”等标签。

本阶段验收：相同经济含义的普通股/ADS 表达与币种表达得到一致的相对估值结果；币种或股份单位变换不会被重复放大。

收入拆分和分部预测的方法保持现有设计，仅传递正确的财年、币种与单位。已有日志、阶段文件和审核流程继续复用；不恢复此前已回滚的复杂补数框架。

如果公共利润计算确需同时服务 Excel 和研究摘要，只抽出必要的小型计算规则，不进行全库重构。测试覆盖两端结果一致，防止只修 Excel、研究摘要仍沿用 A 股公式。

## 7. 验收与交付顺序

| 顺序 | 交付物 | 通过条件 |
|---|---|---|
| 1 | 字段映射和历史关系核对 | 已确认字段可准确查询；尚缺定义与数据逐项列清，未把未知项当作已打通 |
| 2 | 港美历史财务底稿 | 泡泡玛特、苹果按新名称与布局生成；科目原值、缺失和财年正确 |
| 3 | 完整盈利及基本 EPS 推导 | 费用不重复，利润关系明确；变动假设能传递到 EPS；无不同口径强行勾稽 |
| 4 | 同业 PE、目标价与研究输出 | 盈利定义、预测期间、币种和普通股/ADS 匹配；研究结果与 Excel 一致 |
| 5 | 回归结果与最终样例 | 原有测试通过，A 股结果保持兼容；港美边界案例检查通过，披露剩余外部数据限制 |

首批端到端样例采用泡泡玛特和苹果；再用腾讯覆盖研发缺失/包含关系、阿里覆盖港美不同币种版本及 ADS、英伟达覆盖非自然年财年。优先复用已保存响应开展确定性测试，必要时再定向调用测试环境。

关键测试只覆盖真实风险：港股成本误选、SG&A/研发重复、可选字段部分年度缺失、零或负 EPS、利润归属与调整范围混用、税收收益、非自然年财年、汇率和 ADS 重复换算，以及 Excel/研究摘要结果不一致。

A 股先固定已有代表样例的财务和估值结果，再运行原测试集并比较改造后结果。涉及公共代码的变化必须解释差异；无法解释的差异视为回归问题。

所有阶段分别标记完成与尚缺输入。财务底稿能出表不等于完整估值已经打通；只有利润、EPS、PE 和价格单位衔接均通过，才将港美完整估值适配标记完成。
