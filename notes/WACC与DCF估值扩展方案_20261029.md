# WACC 与 DCF 估值扩展方案

日期：2026-10-29。依据当前代码及 output 中现有财务快照梳理；本次交付为方案，未修改估值程序。后续已按用户要求完成接口字段可得性实测，见 [DCF 数据接口实测](DCF数据接口实测_20261029.md)：21 个公司年度均找到 CFO、D&A、Capex 候选；港股债务及租赁等仍缺，WACC 市场参数需另查。

## 1. 建议采用的方案

保留 PE 相对估值，增加以企业自由现金流（FCFF）为基础的 DCF 绝对估值；WACC（加权平均资本成本）作为 DCF 的折现率模块。

用户所说的“waac”按 WACC 理解。最终形成的是“两种估值方法 + 一个资本成本模块”，不是 PE、WACC、DCF 三种平行估值。

建议首版面向非金融企业，采用“现有三年详细经营预测 + 两年过渡预测 + 永续期”。五年是初始配置，不是必须在第五年进入永续期；尚未达到稳定利润率、再投资和资本结构的公司应延长预测期。首版通过现金流所需的附表补齐计算，不要求立即实现完整三表联动。

FCFF 与 WACC 配对、FCFE 与股权资本成本 Ke 配对，这是模型口径的基础。[CFA Institute：自由现金流估值](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

本次检查 output 下六份 facts.json，均无现金流数据区，预测期均为三个年度。样本主要是港美股，不能据此推断所有 A 股来源的覆盖率。代码明确未接入现金流量表；A 股有部分应收、应付和借款字段，港美主干映射尚缺这些 DCF 明细。

四个必须单独处理的口径问题：

1. 当前“营运资本”是流动资产减流动负债。保留原字段，另建“经营性营运资本”，不可直接替换使用。
2. “总负债”包括应付账款等经营负债，不等于有息债务；现有短期借款加长期借款也未必覆盖债券和一年内到期债务。
3. A 股历史 EBIT 在部分情况下由营业利润加财务费用近似取得；财务费用包含汇兑和利息收入等，DCF 需核对具体经营与融资项目。港美营业利润及调整后利润同样不能不经核对直接套用。
4. 总结、研究快照、分析师提示词、规范表与 certify 均假设目标价来自 PE。只新增 Excel 公式会造成研究文字和结果口径不一致。

## 3. 需要补充的数据清单

历史建议取最近 3–5 个完整财年；首版至少覆盖当前三个历史财年。估值日现金、债务和营运资本另取最新已披露季报或中报，并记录其资产负债表日、公告日及到估值日的调整。

| 数据组 | 新增字段或信息 | 必要性 | 主要用途 |
|---|---|---|---|
| 现金流 | 经营活动现金流净额 CFO | 优先补充 | 核验盈利转现金能力，复核 FCFF；不是直接作为折现现金流 |
| 非现金费用 | 固定资产折旧、无形资产摊销；必要时区分使用权资产折旧 | 必需 | 加回已在经营利润中扣除的折旧摊销 D&A |
| 资本开支 | 购建固定资产、无形资产及其他经营长期资产支付现金；适用时资本化研发 | 必需 | 预测 Capex；并购、金融投资和资产处置单列，不用投资活动净现金流代替 |
| 经营流动资产 | 经营应收及票据、存货、预付款、合同资产、适用的其他经营流动资产 | 必需 | 计算经营性营运资本；剔除非经营和融资项目 |
| 经营流动负债 | 经营应付及票据、预收或合同负债、经营性应计费用等 | 必需 | 与经营流动资产匹配；税项归类与经营现金税处理保持一致 |
| 债务 | 短期借款、一年内到期有息债务、长期借款、应付债券、适用租赁负债 | 必需 | WACC 权重、股权价值桥；必须去除重叠分类 |
| 利息与税 | 利息支出及分类、适用税率、重大亏损抵扣和税收优惠 | 必需 | 判断经营现金税、债务成本和利息税盾，三者口径分别保存 |
| 非经营资产 | 受限现金、最低经营现金需求、可加回现金、非经营投资及相应收入 | 必需，金额可为经核实的零 | 从经营价值调整至股权价值，避免重复计算 |
| 其他资本索取权 | 少数股东权益、优先股、可转债、期权等及其处理方式 | 适用时必需 | 将合并经营价值调整至归属普通股股东的价值 |
| 股本 | 各类别普通股数量及交易单位、ADS 比例、适用稀释安排 | 必需 | 每股/每 ADS 价值；当前股本可作明确不变假设，不自动视为充分稀释股数 |
| 资本成本 | Rf、Beta、ERP、适用国家风险溢价、税前 Kd、目标 D/E | 必需 | 计算 WACC；均需来源、时点、定义和可解释的选择依据 |
| 时间信息 | 估值日、实际财年截止日、最新实际截止日、现金流覆盖起止日 | 必需 | 剔除已经发生的现金流，计算剩余期间及折现时间 |

“必需”指需有可核实数值或已明确的估计方案，不代表必须由某一个数据接口直接返回。缺失、确认不适用、披露为零和分析师估计必须是不同状态；现有把部分资产负债缺项置零的逻辑不能直接扩展至 DCF 核心字段。

来源优先级建议：结构化财报接口 → 同期间官方年报及附注核对 → 有来源的人工补录。历史事实不由模型猜测。预测假设可以参考管理层指引、资本开支计划和研究材料，但必须与历史事实分开保存。

实测已确认 Comein finance_search 的现金流报表枚举为 CF。三市场字段探测及覆盖矩阵已保存；A 股 D&A 应从财务指标精确查询“折旧与摊销”，港股来源主要为财务指标，资本开支原值符号与 A/美股不同。结果详见实测报告，仍不能据此承诺全部 DCF 字段已齐备；下一步应核对会计定义并解决明确缺口。

## 4. 经营预测如何延伸到现金流

### 4.1 经营 EBIT 与税

建立 DCF 专用的经营利润桥：报告利润 → 剔除非经营投资收益、融资项目和一次性事项 → 经营 EBIT。收入和主要费用预测复用当前模型，调整项目逐项显示来源，不覆盖原 PE 利润口径。

标准正常盈利情形：

```text
NOPAT = 经营 EBIT × (1 − 经营税率)
FCFF = NOPAT + D&A − Capex − Δ经营性营运资本
```

涉及亏损抵扣、显著税收优惠等时，使用“经营 EBIT − 经营现金税”代替简单税率相乘。不能因为 EBIT 为负就自动确认即时现金退税，也不能直接把基于税前利润的有效税率当作所有阶段的经营税率。

### 4.2 经营性营运资本

```text
ONWC = 经营性流动资产 − 经营性无息流动负债
ΔONWC_t = ONWC_t − ONWC_(t−1)
```

初版可用 ONWC/收入比例预测，但前提是已有按明细核对的历史 ONWC，且比例稳定、业务没有明显季节性或结构变化。进阶使用应收天数、存货天数、应付天数及合同负债比例；应收以收入驱动，存货和应付通常以营业成本驱动。

现金、金融投资和有息债务不能混入经营营运资本。营运资本或其增量允许为负，不强制归零；对负营运资本模式的长期释放能力需单独说明。[Damodaran：估值中的营运资本](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/noncashwc.htm)

### 4.3 D&A 与 Capex

首版允许采用有依据的 D&A/收入、Capex/收入假设；重资产或扩产企业优先依据资本开支计划、资产余额和折旧年限建立附表。预测必须解释增长需要多少再投资，不能把固定资产余额变化直接视为现金 Capex，也不能将并购现金支出混为日常 Capex。

研发费用化/资本化、股权激励以及租赁处理设为显式会计政策。股权激励默认保留为经营成本；若加回，必须同时处理未来稀释或回购成本。租赁需让 EBIT、D&A、Capex/租赁支付和股权价值桥中的租赁负债保持一致，防止漏扣或重复扣除。

### 4.4 预测期限

保持原 PE 的 forecast_periods 三年含义；另设 dcf_periods，前 3 年引用同一经营预测，第 4–5 年按增长率、利润率和再投资向稳态收敛。这样可避免直接扩展全局预测期，导致一致预期和现有固定三列布局连带改造。

过渡期仍需预测收入、经营利润率、经营现金税、D&A、Capex 和 ONWC，而不是只延长 FCFF 增长率。若第五年仍未稳定，增加预测年度或给出方法不适用状态。

## 5. WACC 模块

基础计算使用 CAPM；若需额外国家风险溢价，单列 CRP 并说明风险暴露，避免与 ERP 重复：

```text
Ke = Rf + Beta × ERP + CRP（适用时）
WACC = Ke × E/(D+E) + Kd × (1−T_shield) × D/(D+E)
```

| 参数 | 推荐规则 |
|---|---|
| Rf | 与现金流币种和名义/实际口径匹配的长期无风险利率；不能只按上市地点选择 |
| Beta | 有定义的供应商 Beta，或可复现的回归/同业去杠杆再加杠杆估计；记录基准、窗口、频率、调整方式及杠杆口径 |
| ERP/CRP | 记录来源、估计日期、方法和适用风险暴露；不写死一个全市场通用数值 |
| Kd | 优先当前边际融资成本，例如债券收益率或同币种无风险利率加信用利差；历史利息/平均债务仅作交叉核验 |
| T_shield | 单独评估利息抵税适用性和兑现时间；亏损或受抵扣限制时不机械套用全部税盾 |
| E、D | 市场价值或有依据的目标资本结构；债务账面值近似市场值时披露条件，不用总负债或净债务代替 D |

股权市值按整个发行人资本口径计算。A/H 不同类别股份需各自价格乘对应股数后求和；普通股与其 ADS 代表的权益不能重复计入。避免把模型算出的目标股权价值直接回填 E，造成未经处理的循环依赖。

首版用经解释的固定 WACC；风险与杠杆变化明显的企业，后续增加逐年 WACC 和对应逐期累计折现因子。手工输入 WACC 可作为明确披露的临时假设模式，不能标为已经完成参数分解的 WACC 估计。

现金流币种与折现率一致是必要条件。例如以人民币预测、在香港交易的企业，不能仅因在港上市而直接套港元折现率；先以同一币种得到价值，再换为交易币种。[Damodaran：资本成本](https://pages.stern.nyu.edu/~adamodar/pdfiles/papers/costofcapital.pdf)

## 6. DCF 模块与目标价

```text
终值 TV_n = 稳态 FCFF_(n+1) / (WACC_terminal − g)
经营资产价值 = 未来各期 FCFF 的现值之和 + 终值现值
普通股股权价值 = 经营资产价值
                 + 可加回现金 + 单独估值的非经营资产
                 − 有息债务 − 少数股东价值 − 优先股及其他适用索取权
每普通股价值 = 普通股股权价值 / 相匹配的普通股数
每交易单位价值 = 每普通股价值 × 报表币种兑交易币种 × 每交易单位普通股数
```

桥接项目与 FCFF 的范围一致：若采用合并经营现金流，须处理非控股权益；已经纳入经营 EBIT 的投资收益，不能在桥中再次无条件加回对应投资资产。少数股东权益账面数仅可作为有说明的估计，不能默认等同其价值。零有息债务时债务权重为零，净现金不能导致负债务权重。

终值有三项约束：

1. WACC_terminal > g；不满足时禁止输出有效终值。
2. g 与现金流币种下的长期名义增长及公司成熟状态一致，不直接沿用高速增长期增速。
3. 独立计算第 n+1 年正常化利润及再投资，保证增长有相应投入；可用“再投资率 = g/稳态 ROIC”交叉校验，不默认 Capex 永远等于折旧而同时保持正增长。[Damodaran：终值与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)

折现依据估值日及各期现金流日期计算。期末法下采用实际剩余期限，年中法必须标明假设；终值按对应期末折现。估值日在财年中间时，应有剩余期间现金流估计及与最新资产负债表的桥接，不能把已发生的现金流再次按完整首年折现。若剩余期间只能按比例估计，要显示季节性局限。

金额和股数转换集中处理：现项目金额常为“亿”、股数为“百万股”，每股计算需相应乘 100，不能把不同量纲直接相除。ADS 与普通股转换只执行一次。

## 7. 展示与比较

保留现有七张表，在启用 DCF 时建议新增四张：

| 新表 | 内容 |
|---|---|
| 资本成本 | Rf、Beta、ERP/CRP、Kd、税盾、资本结构及 WACC；参数来源与日期 |
| 现金流预测 | 历史现金流及所需附表、三年详细预测、过渡期、经营税、D&A、Capex、ONWC 和 FCFF |
| DCF估值 | 折现时间与因子、经营资产价值、终值、股权价值桥及每股/每 ADS 结果 |
| 敏感性分析 | WACC × g 的价格矩阵、关键经营假设与情景比较 |

总结增加 PE 价格、DCF 价格、各自较现价空间、采用的主估值方法、WACC、g、终值现值占比和可用性状态。PE 当前口径是“当前合理价格”，DCF 也应回到同一估值日后比较。

首版并列展示，不自动平均两个价格。后续若引入权重，需要解释适用性和依据；不能因一个结果更高就赋予更高权重。数据不足的 DCF 显示缺口，不以零替代输入，也不沿用旧值。

DCF 经营情景分别调整增长、利润率、Capex、营运资本等；参数敏感性单独展示，不能复制现有 PE 悲观/乐观的 ±15% 做法。敏感性表只计算 WACC>g 的格子；若终值再投资取决于 g，应同步重算。终值占比高给出解释性提示，不据此直接认定估值无效。

- valuation_results.json：PE/DCF 各自结果、主方法、有效性与数据缺口。

输入需要区分事实、估计和预测，记录值、单位、币种、期间或时点、来源、获取日期、方法与缺失状态。常用百分比内部统一为小数，历史与预测使用明确期间标识。

流程建议：历史财务及 DCF 补数 → 原收入及利润预测 → 现金流假设/过渡期；资本成本可独立准备 → DCF 计算 → 多方法研究快照 → 研究底稿 → Excel → 验收。

方法默认仍为 PE，可显式启用 PE+DCF；预留单独 DCF 的加载能力，不让其硬依赖同业 PE。DCF 缺数据时保留有效 PE，并将 DCF 标为缺口状态及整体部分完成，不把请求的全部方法记为成功。参数、汇率或基础事实变化后使下游结果失效；续跑不能仅凭旧 completed 标志跳过新增计算。

## 9. 分阶段落地与验收

| 阶段 | 工作与交付 | 通过条件 |
|---|---|---|
| P0：数据与口径验证 | 各选 A/H/美股一个代表样本，形成逐字段覆盖表、接口原始响应、年报核对及缺口清单；确定租赁、税和股份政策 | D&A、Capex、ONWC、债务、现金、资本成本有可行获取方案；币种和日期明确 |
| P1：现金流与 WACC | 新增事实/假设规范和确定性计算，允许有来源的手动参数；完成三个样本经营价值到股权价值的手算对照 | 不依赖整套三表也能复核 FCFF 和 WACC；核心缺失会被明确拦截 |
| P2：完整输出 | 接入流水线、四张新表、敏感性、总结和研究底稿；补方法配置与旧任务迁移 | Excel、研究快照和文字输出一致；旧 PE 模式正常，DCF 缺失不冒充成功 |
| P3：适用范围扩展 | 扩展重资产、负营运资本、租赁显著、亏损及复杂股权样本；按需要增加逐年 WACC/更长预测期 | 每类特殊口径可解释并通过针对性验证，再宣布覆盖 |

优先使用已有项目样本做交叉验证：泡泡玛特关注零售现金周期和租赁；中芯国际关注重资产资本开支与折旧；谷歌关注美元、股权激励与多类别股份；联想关注非自然财年和负营运资本。它们是待核对的测试方向，不代表本次已完成对应财务判断。另补一个 A 股样本，避免把港美验证视为三市场验收。

必要验收包括：

1. 在正现金流、固定预测与固定 g 条件下，提高 WACC 应降低经营价值；提高 Capex 或 ΔONWC 应降低对应期 FCFF。
2. 股权价值桥单独加减项目的符号正确；现金、债务、少数股东和 ADS 无重复计算。
3. WACC≤g、必要值缺失、币种未确认、Beta 无定义、债务分项重叠时明确提示；净现金、负营运资本、短期负 FCFF 不被机械判错。
4. 年中估值不重复纳入已实现现金流，港美按实际财年计算；历史 CFO 与利润法 FCFF 差异可解释，利息和税费分类按准则核对。
5. 用独立数值基准核对 WACC、FCFF、终值、股权桥和每股价值，并实际重算工作簿公式。现有 openpyxl 建表与公式引用检查不能单独证明 Excel 数值已计算正确。
6. PE 旧任务、续跑、仅重建、汇率刷新以及新参数变更后的失效重算均有明确行为。旧文件不会因新增代码而自动获得 DCF。

金融企业应先进行方法识别：银行、保险等的债务和再投资含义特殊，另设计 FCFE、DDM 或剩余收益模型，不把工业企业 FCFF 模板强行套用。[Damodaran：金融服务企业特征](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/financialsvccompanies.htm)

## 10. 首版范围建议

首版交付目标：非金融公司、PE+FCFF DCF 并列、固定 WACC、可配置五年起步的预测期、永续增长终值、经营现金流附表、股权价值桥、三种经营情景及 WACC×g 敏感性、可追溯数据与验证。

优先解决数据与口径，再接入模型和展示。对于来源缺口，交付明确的补数清单和受支持范围；不先填通用 WACC、Capex 比率或永续增速，制造表面完整的估值结果。
