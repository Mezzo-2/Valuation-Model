# 港美股财务底稿目标样式

更新：2026-10-27。本版按用户最新要求统一使用 A 股模板；此前港美四列纵向版式不再作为规范。

每家公司一张历史财务表，沿用 A 股 A:D 利润表、E 列间隔、F:I 资产负债表的左右分栏，下方展示历史指标和市场快照。两侧均列最近三个完整财年及实际截止日期。不设独立口径批注列，必要差异直接写入科目名称；来源、数据日期和 EPS 单位集中在表内说明。

金额显示两位小数，EPS 四位小数，保留底层原精度。缺失统一为短横线“-”，使用数字字体并右对齐、无缩进；公式返回的缺失值遵循同一规则，真实零保留数字零。可选科目缺一年不删除其他年度数据；存货、无形资产保留行。接口没有返回不等于年报没有披露。

## 利润表摘要

| 科目 | 港股 | 美股 |
|---|---|---|
| 营业收入 | 已返回总收入 | 已返回总收入 |
| 收入对应成本 | 销售成本 | 营业成本 |
| 毛利 | 来源值 | 来源值 |
| 销售、管理费用 | 分列适用科目 | 使用销售及一般管理费用（SG&A） |
| 研发费用 | 有独立值时列示；包含于管理费用时为“其中：研发费用” | 有独立值时列示；包含于 SG&A 时为“其中：研发费用” |
| 营业利润 | 营业利润 | **营业利润（SOPR）** |
| 税前利润 | 来源值 | 来源值 |
| 所得税费用 | 来源值，保留符号 | 来源值，保留符号 |
| 净利润 | 合并净利润 | 净利润（扣非） |
| 少数股东损益 | 独立值或同口径合并净利润减归母净利润 | 同一规则；调整范围未确认时保留“—” |
| 归母净利润 | 来源值 | 来源值；不凭名字认定与扣非净利润同范围 |
| 基本 EPS | **基本每股收益** | **基本每股收益（扣非）**，Basic EPS / SBCOC |
| 历史基本加权平均股数 | 独立取得则列示 | 独立取得则列示；不以未配对的利润和 EPS 反推 |

少数股东损益名称不加“计算”后缀。研发是否为其中项须有依据，不依靠同名猜测；预测公式不重复扣减。历史利润保留原值，不用未知残差补造经营或非经营收益以凑平。

## 资产负债表和指标

保留现金及现金等价物、存货、固定资产、无形资产、流动/非流动资产与资产总计、流动/非流动负债与负债合计、归母股东权益、少数股东权益、股东权益合计，以及流动资产减流动负债的营运资本。字段范围更宽时不能误称 PP&E 净额；夹层权益未返回不从平衡差额倒推。

指标包含收入增速、毛利率、适用费用率及税费/税前利润。费用率随港美适用科目变化。市场快照的股价、市值使用交易币种，基本 EPS 使用财务数据对应币种和普通股单位。

## 币种与后续估值

优先识别年报列报币种。接口明确返回美元时金额按美元保留，不能改标签成为人民币。接口没有币种且年报检索也不能明确确认时，表头标“币种待确认”，完整估值要求补齐。

后续按收入、毛利、适用费用、营业利润、税前利润、税后净利润、少数股东损益和归母净利润推导基本 EPS。默认像 A 股一样直接引用财务数据页的当前股本，假设持平，不重复列示预测加权股数或普通股股东利润。财务费用和营业外收支复用原有字段，联营损益等仅在实际适用时列示；不再统一预留经营/税前/普通股三个调整项。确有优先股股息时才扣减。目标价乘报表币种兑交易币种汇率及每交易单位普通股数，各应用一次；同币种汇率为 1。ADS 分母按已核实比例转成普通股数，比例同时在财务快照中展示。ADS 比例、汇率或可比 PE 定义缺失时明确报告缺口。

本轮实际财务样本保存在 `output/adaptation_20261026/<证券代码>/historical_financials.xlsx`。`integration/` 中的港美七表文件仅用于公式校验，不能作为真实投资预测。

## 统一建表规则

A/港/美共用 `valuation/workbook/build.py` 的七表生成函数，市场差异通过 `market_config.py` 的科目、假设和公式规则传入。总结使用 A:K 左右分栏和颜色说明；运营成本与利润预测使用 A:H（A 科目、B:D 历史、E:G 预测、H 备注）。恢复成本毛利区、费用区，以及收入/归母利润同比等展示。长科目名换行，长备注在原备注列内展开；不为版式凑齐而补零或改动财务口径。
