# DCF与WACC研究与版式修复方案

日期：2026-11-05。状态：已实施，见[修复验收](DCF与WACC研究与版式修复验收_20261105.md)。一个估值金融分析师Agent负责完整DCF估值，Capex为主要研究重点；其他参数轻量整合，不逐项设置研究任务或强制编写判断依据。

## 1. 问题与当前取值

上一版完成了计算链，本次集中改善Capex判断和模板一致性，不将全部参数重新组织成专项研究。

现有`assumptions.py`中已经有一个假设整理Agent，但没有绑定搜索工具。程序先固定获取公司财务、国债收益率、股价/指数周线及一轮公告摘要，再把这些材料和原成本预测交给Agent生成输入。公告检索集中于最近两份年度报告、一个综合问题、最多四个命中；Agent无法因发现疑点而补搜或展开原文。此前分部和成本研究材料也未作为完整证据包复用。

当前科大讯飞样例中的主要值：

| 参数 | 当前值 | 实际形成方式及问题 |
|---|---|---|
| D&A/收入 | 三年9.0% | 2023—2025年约9.82%、10.22%、8.97%，取最近一年约数；继续作为已有校准基础 |
| Capex/收入 | 三年11.6% | 历史约20.77%、13.79%、11.62%，沿用最近一年；扩产、算力投入、无形资产及资本化研发的覆盖需要核实 |
| ΔONWC/Δ收入 | 三年15% | 基于简化历史经营项目作正常化判断，交由Agent结合已有材料整合 |
| 经营税率/税盾税率 | 均15% | 沿用原正常化假设，不另设税务专项研究 |
| Rf | 1.65% | 接口候选值，采用2026-10-30；返回日期与元数据存在冲突，尚待核实 |
| Beta | 1.2413 | 程序使用股票与沪深300两年周频收益率回归，103组收益率；沿用现有计算流程 |
| ERP/信用利差 | 5.5%/2.0% | 由Agent结合当前配置及已有材料选定，不强制分别检索并写长依据 |
| 稳态参数 | g 3%、EBIT利润率5%、D&A 8.5%、Capex 9.5%、增量营运资本12% | 由Agent负责与三年预测衔接；其中稳态Capex纳入本次重点研究 |

上述为当前科大讯飞样例的值，不是所有公司的统一默认值。三年使用相同比率可以保留，不要求刻意制造逐年变化。

原方案中对稳态、税务、营运资本、融资及价值桥接逐项专项研究的安排取消。Agent仍对整个DCF负责，发现明显矛盾时作必要处理，但不把所有参数都转成独立研究课题。

## 2. 一个Agent负责完整DCF，重点研究Capex

在现有DCF阶段升级已有Agent，不另拆一个只管Capex的Agent，也不增加多层研究和评审流程。

职责覆盖：整合已有三年经营预测，选定DCF假设和WACC参数，结合Capex研究形成FCFF及稳态输入，检查现金债务等股权价值调整，并解释最终DCF与PE的差异。比率、WACC、折现、终值和敏感性的数值计算继续由程序完成。

流程：读取已有数据与研究 → 重点补搜Capex → 整合完整DCF输入 → 程序计算与基本校验 → Agent给出简短估值解释。

### Capex的主要研究内容

- 先读取近年Capex金额、收入占比以及前序研究中已有的投入信息。
- 通过进门检索公司公告、年报及研报，重点寻找资本开支计划、扩产或算力投入、项目投产进度，判断未来三年投入强度能否沿用最近一年。
- 结合公司的主要投入类型，确认Capex是否已包含资本化研发、无形资产等，避免重复扣除。
- 给出三年Capex/收入和稳态Capex/收入；有明确金额计划时可先确定金额，再由程序换算比率。
- 留一段简短判断和少量主要来源即可，不要求逐年各写一篇说明。没有明确计划时，可基于历史和现有经营信息估计，并简短注明。

### 其他参数的处理

- D&A、营运资本、税率、经营利润调整等复用历史校准、原成本和经营预测，Agent作必要整合与调整。
- Rf、Beta及资本结构沿用当前取数和计算流程；ERP、债务成本及其他稳态参数由Agent结合已有材料选定。
- 现金、债务和股数沿用已取得数据及现有桥接逻辑。
- 不为上述项目逐项设置检索任务，不要求每项都有一段判断依据；现有数据来源可以直接沿用，只有明显异常或影响结果的特殊处理才简短说明或补查。

只保留必要的数值、单位、日期、WACC大于g及引用联动检查，不增加要求Agent逐项论证的检查流程。保持现有三年显性期及稳态辅助年。

### 工具与输出保持轻量

- 复用原进门检索及原文读取能力，以Capex为默认检索重点；先读已有材料，少量定向补搜，材料够用即停止，不要求完成固定数量的研究任务。
- 输出完整`dcf_inputs.json`，不只输出Capex。保留`dcf_results.json`作为程序计算结果。
- 重点解释Capex的取值，另给一段整体DCF估值说明。其他参数的详细理由为选填，不因未写长依据而阻止出表。
- 原始接口和检索来源保存在已有日志中。读取事实沿用原来源记录，研究假设不冒充披露值；不另建覆盖所有参数的研究档案体系。

分析师对完整DCF的参数组合和结果解释负责，程序保证计算正确。无需为凑齐说明而重复搜索，或把Capex研究扩展成所有科目的附注审查。

## 3. 按原模板重新组织新增两页

现有七页均未冻结；WACC单独冻结B3、DCF单独冻结D3。新页还使用了不同的列宽及期间列位置。WACC依据列宽76，DCF依据列宽58，长来源段落把多行撑到72—162磅，打断了计算表阅读。虽然字体配色部分复用了原样式，整体布局并未统一。

统一以当前七表为模板。本次只修复新增两页及必要的总结引用，保留原表的数据和公式。

| 项目 | 修复决定 |
|---|---|
| 冻结与打开位置 | 两个新页取消单独冻结，清理残留窗格/选择状态；默认从A1、正常缩放打开，保持原七表的使用习惯 |
| 页头与字体 | 复用原模板标题、模块栏、字体字号、留白与输入/公式/跨表引用/负数配色 |
| 列宽 | DCF指标列按原预测页32、年度列13、备注列约36—42；WACC参考原估值页的参数表，不再设置超宽来源列 |
| 行高 | 主计算区沿用常规18—22磅；长指标必要时两行。完整说明移到页下方专门区域，允许自动换行，不靠截断隐藏内容 |
| 数字与单位 | 金额、每股值、比率、日期各用原模板格式；金额币种与单位统一标注，撤去DCF左侧独立的宽单位列 |
| 依据展示 | 重点展示Capex简短判断及主要来源；其他项目按需附简短口径或来源，不为每项预留长说明 |
| 缺失和不适用 | 沿用右对齐“-”，关键缺项给出具体项目，不以数值0替代 |

### DCF页

按“历史校准与预测假设 → FCFF计算 → 终值与归母股权价值桥接 → WACC×g敏感性”分区，Capex说明就近简短展示，必要的长说明放在页下方。

期间表沿用原预测页的位置：A列指标，B—D列三个历史年，E—G列三个预测年，H列稳态辅助年，I列简要备注。历史栏只填可核实的历史数据及比率，不能按同口径还原的历史FCFF/调整显示“-”，不为排版补造历史值。

敏感性继续放在DCF同一页，保留基准中心格及g变化时再投资重算。辅助计算集中排列，不穿插长叙述。价值桥接使用相邻的标签与数值，撤去原表中横跨多列的无意义空白。

### WACC页

按“股权成本 → 债务成本 → 资本结构 → WACC结果 → 依据说明”分区。主体采用项目、数值、单位、口径、日期、简要依据六列；直接引用已有行情及债务，重复输入减少到必要的覆盖项。直接融资成本和利差法明确显示适用项，不把未采用的空参数伪装成缺口。

原九张表数量保持不变，不新建独立敏感性或来源sheet。总结仍并列展示PE与DCF。

## 4. 工程改动

| 位置 | 计划变更 |
|---|---|
| `valuation/dcf/assumptions.py` | Agent负责完整DCF输入和结果解释，增加以Capex为重点的检索能力，不逐项布置研究任务 |
| `valuation/dcf/fetch.py`、`write.py` | 复用已有取数和材料，让Agent能在整合DCF时补搜Capex，沿用现有日志 |
| `valuation/dcf/calculate.py` | 保留确定性WACC/FCFF及必要校验；取消所有参数必须填写判断理由的统一要求，详细解释改为选填 |
| `valuation/dcf/workbook.py`、共享样式 | 按原模板重排两页，重点展示Capex说明，统一视图和数字格式 |
| 总结、研究底稿、验表及测试 | 总结和敏感性改用可解析的结果锚点，移除依赖旧固定坐标B46、D61等的引用，避免重排后错链；验证全文和当次数值一致 |

原收入、费用与PE模型维持原口径。DCF如需调整经营利润，独立列示来源和桥接，不直接回写原利润预测。

## 5. 实施顺序与验收

1. 先固定模板规则并完成新增两页排版，参数先不动，对照原模型确认变化仅为展示和引用位置。
2. 给完整DCF分析师Agent接入Capex重点检索，其他参数沿用现有流程并轻量整合，同时取消逐项强制理由。
3. 重跑科大讯飞，对照Capex调整及其对DCF的影响，检查完整DCF和WACC正常生成。
4. 复用已有计算回归检查，补查检索结果传入Capex、参数联动及实际阅读效果，再更新验收说明。

通过条件：

- 同一个Agent输出完整DCF输入，并实际针对Capex检索和给出简短判断；其他参数不要求逐项补搜或逐项解释。
- 相同输入可重算出相同WACC/DCF；Capex口径和单位正确，避免资本化研发等重复扣除，三年经营预测继续复用原模型。
- 修改经营比率、WACC参数和g时，FCFF、敏感性中心、DCF和总结同步更新；缺失、零值、覆盖项与不适用项正确区分。
- 新检索的Capex材料符合估值时点，沿用现有来源记录，不将研究假设包装成披露事实。
- 新旧页并排检查字体、列宽、行高、冻结、打开位置及滚动体验，主计算区没有长文本撑高、截断、溢出或大块空白。用实际工作簿打开检查和渲染检查补足自动化测试。
- 布局调整后所有结果引用仍正确；原经营/PE公式不因排版改变。敏感性仍在DCF页，显性期仍为三年。

最终交付：修复后的九表工作簿、简短Capex研究结论及主要来源、完整DCF估值解释和必要的验收说明，不要求逐项参数研究报告。
