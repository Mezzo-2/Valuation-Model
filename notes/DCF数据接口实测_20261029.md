# WACC / DCF 数据接口实测

实测日期：2026-10-29，北京时间。结论基于本轮实际联网返回，不使用历史缓存替代查询，不使用大模型补造财务值。本次未修改估值运行时、原有 facts 或 Excel。

## 1. 结论

当前进门接口能够返回 DCF 的主要现金流基础项：经营现金流、折旧摊销、资本开支候选在全部 21 个公司年度样本中均有数值。此前项目没有这些数据，主要是尚未查询和适配，不能理解为接口完全不提供。

仍不足以直接宣布三市场 DCF 数据齐备：

- A 股：经营营运资本的主要分项、借款与债券等分项、租赁负债和利息费用已有返回；需核对分类、受限资金以及缺失科目的不适用/零值含义。
- 美股：现金流、债务合计及长短期债务可取；应付为“应付账款及应计”聚合项，营运资本、租赁及非经营资产仍需定义核对。
- 港股：现金流三项与应收、存货、应付可取，但借款/债务余额、租赁负债、独立利息支出、预付款及其他应收应付等仍未取到；测试环境也未补出本轮所查的这些目标字段。
- WACC：财务指标专项查询没有返回 Beta、WACC、Rf、ERP 和债务资本成本；本轮行情和财务快照也未返回 Beta。需要另行验证市场风险与宏观数据来源，不能由这些财务响应直接生成完整 WACC。

“有返回值”是字段可得性结论，不是年报逐项核对通过率；资本开支范围、租赁、调整后利润和经营营运资本的会计定义仍需核实。

## 4. 已验证的名称与来源

| 市场 | 目标 | 实际有效名称 | 实际来源 |
|---|---|---|---|
| A 股 | CFO | 经营活动现金流量净额 | 现金流量表 |
| A 股 | D&A | 折旧与摊销 | 财务指标 |
| A 股 | Capex 候选 | 资本性支出；购建固定资产等支付现金 | 现金流量表 |
| 港股 | CFO | 经营活动现金流净额 | 财务指标 |
| 港股 | D&A | 折旧及摊销 | 财务指标 |
| 港股 | Capex 候选 | 资本性支出；购买固定资产 | 财务指标 |
| 港股 | 基础营运项目 | 应收账款、存货、应付账款、合同负债 | 财务指标 |
| 美股 | CFO | 经营活动现金流净额 | 现金流量表 |
| 美股 | D&A | 折旧损耗摊销；折旧与摊销 | 现金流量表；利润表 |
| 美股 | Capex 候选 | 资本性支出 | 现金流量表 |
| 美股 | 经营应付候选 | 应付账款及应计 | 资产负债表 |
| 美股 | 债务 | 短期债务及长期债务流动部分、长期债务、债务合计 | 资产负债表 |

A 股只查 CF、使用一般“折旧/摊销”词没有召回 D&A；扩大查询后，用精确“折旧与摊销”从财务指标取得 6/6。单字段再次查询及相同请求重复均取得相同六项数值。实现时应把该指标作为有来源的独立读取，不需要用模型猜测。

美股最初查询“应付账款”未取得目标项，默认清单发现“应付账款及应计”后，精确名称取得 6/6，单字段及重复查询结果相同。只用 A 股名称查询，会把可得数据误判为缺失。

名称不是完全固定的返回主键：本轮港股同一资本开支候选可因请求词组合显示“资本性支出”或“购买固定资产”；应保留原名，并使用经过核实的白名单。港股实际 source 为财务指标，不能因只接受 source=现金流量表而把有效返回丢掉。

## 6. 数值勾稽与语义风险

离线对保存响应做了九组、合计 54 个算术核对，均在按亿计 0.0002 的容差内通过：

| 核对 | 通过/检查数 | 能说明什么 |
|---|---:|---|
| A 股 D&A = EBITDA − EBIT | 6/6 | 指标间算术一致；不单独证明其符合目标经营调整口径 |
| A 股两种 Capex 名称金额相等 | 6/6 | 本轮映射金额一致 |
| 港股两种 Capex 名称金额相等 | 9/9 | 本轮映射金额一致 |
| 美股现金流表与利润表 D&A 相等 | 6/6 | 两处金额一致，不应重复加回 |
| 美股债务合计 = 短期及流动部分 + 长期债务 | 6/6 | 债务主干可勾稽；租赁包含范围仍需确认 |
| 美股净债务 = 债务合计 − 现金与短期投资 | 6/6 | 供应商扣除的是现金加短期投资；不是仅扣现金 |
| 美股“杠杆自由经营现金流” = CFO − Capex | 6/6 | 本轮实际算术关系；不能因此命名为可直接按 WACC 折现的 FCFF |
| 美股“营运资本” = 流动资产 − 流动负债 | 6/6 | 这是原有广义营运资本，仍非经营性 ONWC |
| A 股应收合计 = 应收账款 + 应收票据 + 应收款项融资 | 3/3 | 在三个分项均有值的宁德时代年度中成立，须防止融资应收重复计入 |

还需注意：

- A 股虽直接返回“企业自由现金流量”，例如宁德时代 FY2023 为 -389.9427 亿元，但该值不能从“CFO 928.2612 − Capex 336.2490”直接解释。需取得供应商完整定义、再投资和税项口径后才能用作模型对照，不能直接取其历史序列增长后折现。
- 美股还有“折旧与摊销补充”，金额与主 D&A 不同，例如谷歌 FY2025 为 216.53 亿美元、主 D&A 为 211.36 亿美元；该补充项不能与主项无条件相加。
- 港股“经营所得现金”和“经营活动现金流净额”是不同项目。泡泡玛特 FY2025 分别为 147.0478 与 108.6515 亿元，不能互换。
- 正式环境同代码、同期间、同字段名、同 source 的金额未发现本轮冲突；默认清单中“其他综合收益”在资产负债表和利润表有不同值，共六组同名情况。这是存量/流量等不同来源口径，不能按名称直接去重或认定为数据波动。
- 部分 A 股 CF/指标的 publishDate 为本次查询日，和资产负债表返回日期不同；该字段是否为公告日、更新日或兜底值需确认。本轮验证当前可得性，不据此宣称历史时点可回溯。

## 8. 测试环境对照

测试环境三次定向查询中，与正式环境共同取得的同代码、同期间、同名称、同 source、同币种金额项目共 348 项，数值均一致。两环境请求词集合并非完全相同，因此不把这个计数解释为完整响应一致。

港股短期借款、长期借款、债务合计、租赁负债及独立利息支出，在本轮测试查询中仍为 0/9；预付款、其他应收应付等目标精确项也没有补出。未发生修改项目默认连接或用测试环境结果覆盖原模型的行为。

## 9. 下一步的数据动作

1. 可立即设计历史数据适配：CFO、D&A、Capex 候选、A 股经营/融资科目、美股债务主干。适配前固定名称、来源和符号规则，并保留历史原值。
2. 优先向数据方补要港股债务余额：短期、长期、一年内到期、债券、租赁、独立利息；还需预付款、其他经营应收应付的细分及是否不适用说明。
3. 向数据方确认三市场 Capex 的资产范围、D&A 是否含使用权资产折旧、美股债务是否含租赁，以及“营运资本增减”“企业自由现金流量”等衍生指标公式。
4. 补查年报附注：经营/非经营资产负债分类、受限现金、租赁、资本化投入与税项；不把财务费用、总负债、净流动资产作为对应缺项的替代值。
5. 下一轮另行验证 Beta、Rf、ERP、边际 Kd 的市场数据来源。本轮仅证明所查财务与行情入口未提供完整 WACC 输入，尚未穷尽供应商全部市场数据工具。

优先顺序判断：A 股可先做数据适配样板；美股需带上聚合项目与会计定义核对；港股要先解决债务/租赁余额及经营营运分项缺口。此为基于本轮样本的工程安排，不是全市场覆盖保证。
