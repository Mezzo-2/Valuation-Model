## 2. 分层绿色视觉规范



### 2.1 主色阶

采用同一绿色方向的纯色填充，通过降低饱和度并提高明度形成层次。深色集中在标题和主要分区，浅色用于分组和表头，正文大部分保持白底。


| 层级/角色 | 色值      | 文字搭配              | 应用位置                       |
| ----- | ------- | ----------------- | -------------------------- |
| 深墨绿   | #24463A | 有色底用白字；白底标题使用该色文字 | 页面标题文字、估值概览标题、最重要结果区域的边线   |
| 中深绿   | #3B6554 | 白字                | 财务预测、经营假设、收入构建、费用计算等一级分区标题 |
| 柔绿    | #BCD2C4 | 深绿 #213A2E        | 各业务分部、费用类别等二级分组标题          |
| 浅绿    | #DCE8E0 | 深绿 #213A2E        | 预测年份列头、普通表格列头              |
| 极浅绿   | #EAF2ED | 标签用深绿；数值保留其角色字体色  | 归母净利润、EPS、目标价等少量重点结果行      |
| 近白绿   | #F4F7F5 | 深色正文              | 公司介绍字段标题、历史年份列头            |
| 白色    | #FFFFFF | 按文字或数值角色确定        | 数值正文、公司介绍内容及大多数单元格         |


其他基础色：正文标签 #24352C，辅助文字 #65756B，普通细分隔线 #CCD8D0，历史/预测分界线 #8CA795。

### 2.2 区域应用规则

1. **公司介绍区：轻。** 公司名称用深墨绿文字，信息主体白底，字段标签可用近白绿。顶部完整展示公司资料，视觉上保持紧凑。
2. **估值概览区：重。** 区域标题用深墨绿底、白字；目标价、估值区间等关键结果使用极浅绿底和加粗，让读者进入估值部分后迅速找到重点。
3. **财务预测区：清晰。** 一级分区用中深绿；历史表头近白绿、预测表头浅绿；普通财务行白底，小计加线。
4. **业务与费用分组：次一级。** 使用柔绿标题行，避免每个业务块都采用最深颜色。
5. **研究观点区：延续现有内容。** 投资逻辑、未来展望、主要风险的标题使用同级中深绿；文字不删改、不拆分，正文保留原有组织方式。

同一层级跨工作表使用同一色值，不给每张表另选一套绿色。采用纯色，不做渐变、阴影或高饱和亮绿大面积填充。深色填充主要限制在标题行，不覆盖整个数值区。合计线、字重和 A/E 标签共同表达层级，不只依靠颜色。

### 2.3 数值角色与主题配色分开


| 数值角色    | 字体颜色       | 规则                                   |
| ------- | ---------- | ------------------------------------ |
| 可编辑数字输入 | 蓝色 #0000FF | 用于手动假设及需人工维护的数值；代码、日期、标签及只读导入数据不机械染蓝 |
| 同表公式    | 黑色 #000000 | 同表计算结果                               |
| 跨表引用    | 绿色 #008000 | 正文中引用本工作簿其他工作表的公式                    |
| 外部文件引用  | 红色 #FF0000 | 仅在实际存在时保留该角色，不新增外部链接                 |


主题绿色主要作用于标题、底色和线条；正文中的绿色字体专门用于跨表引用。深色表头统一白字，正文与结果行保留数值角色色。浅色结果行的填充应足够淡，保证蓝色输入和绿色引用都可读。正负涨跌用正负号表示，不再用红绿填充表达行情方向。

### 2.4 字体、行高和对齐

- 中文建议统一微软雅黑 10—10.5 pt；交付端字体不可用时，使用经实际检查的苹方等替代。英文与数字统一 Arial 10 pt。
- 页面标题 15—16 pt，左对齐；模块标题 11 pt 加粗；列头及数值正文保持一致字号。摘要关键价格可用 14—16 pt。
- 普通数值行高 18—20 pt，表头 22—24 pt；大分区之间使用一个 8—12 pt 间隔行。备注所在行不做专项高度调整。
- 文字左对齐、数值右对齐、年份居中；单行数据垂直居中。公司主营业务可按内容占一至两行，不删减介绍原文。
- 对毛利、EBIT、归母净利润等小计使用加粗和细顶线；最终 EPS、目标价使用较强底线或双底线。普通明细不逐格画边框。
- 不合并计算区域、年度数据列或输入单元格；必要的跨列显示仅用于标题与公司介绍展示区域，不涉及备注改造。



## 3. 数字统一保留两位小数

所有财务数值，包括摘要和明细，均显示两位小数。底层值、计算精度及单位保持不变。


| 数据类型                | 展示示例                 | 示例格式代码                        |
| ------------------- | -------------------- | ----------------------------- |
| 金额（亿元）              | 1,234.56，负数 (123.45) | `#,##0.00;(#,##0.00);0.00;@`  |
| 股价/EPS（元/股）         | 39.11、0.63           | `0.00;(0.00);0.00;@`          |
| PE/PB（倍）            | 61.80x               | `0.00"x";(0.00"x");0.00"x";@` |
| 增速、利润率、费用率          | 29.00%，负数 (5.00%)    | `0.00%;(0.00%);0.00%;@`       |
| 目标价相对现价变动           | +15.00%、-15.00%      | `+0.00%;-0.00%;0.00%;@`       |
| 股本（百万股）             | 1,278.83             | `#,##0.00;(#,##0.00);0.00;@`  |
| 调整系数、销量指数、换算因子及单价参数 | 1.00、175.50、0.20     | `#,##0.00;(#,##0.00);0.00;@`  |
| 年份/期间标签             | 2025A、2026E          | 保留期间含义，不显示成 2026.00           |
| 日期                  | 2026-09-21           | 维持正确日期显示，日期单元格可用 `yyyy-mm-dd` |
| 股票代码                | 002837               | 保留文本及前导零，不改成数值小数              |


零值同样显示两位小数，如 0.00、0.00%、0.00x；原有缺失、空白或不适用标记保持原义，不能转换成数值零。两位小数规范针对数值单元格；本轮不改写备注或研究叙述中的文字数字。

单位就近标注：财务金额默认“人民币亿元”，每股数据为“元/股”，股本为“百万股”，特殊指数与单价保留原单位。只修改数字格式，不对存储值做 ROUND 或改变换算关系。

## 4. 首页布局：公司介绍在最上方

保留“总结”工作表名称，将公司介绍作为页首完整区域，其后进入估值。原有公司资料和研究文字均保留，不以减少内容来压缩首页。


| 建议位置/顺序        | 内容                                    | 呈现方式                                              |
| -------------- | ------------------------------------- | ------------------------------------------------- |
| 第 1—7 行左右：公司介绍 | 公司名称、股票代码、行业、主营业务、法定代表人等现有资料          | 公司名称作为标题；短字段横向组合；主营业务单独占一至两行。深墨绿标题文字、白底内容、近白绿字段标签 |
| 公司介绍下方：估值概览    | 当前股价、目标价、估值区间、潜在涨跌幅、目标 PE、对应 EPS、现有评级 | 深墨绿分区标题；标签与数值紧凑排列，关键结果使用极浅绿底；明确已有估值年度与金额单位        |
| 估值概览之后：财务预测    | 2025A—2028E 的现有财务概览指标                 | 年度列等宽，历史与预测使用不同明度表头；金额、比率、EPS 分别采用两位小数格式          |
| 财务预测之后：经营假设    | 毛利率、费用率、税率等现有关键假设                     | 中深绿标题，清晰的年度矩阵                                     |
| 后续：研究观点        | 现有投资逻辑、未来展望、主要风险及原有模型说明               | 保留全部条目和原文，统一区域标题颜色与字重                             |


现有多周期涨跌幅、总市值和流通市值保留为估值区域内的次级行情信息，可放在概览的侧方或下方；不再夹在公司介绍与核心估值之间。若合并重复展示的“当前股价”，保留一个公式链接的显示位置即可，不新增手填副本。

公司介绍预计使用 5—7 行，具体高度以完整展示原文为准。公司介绍与估值之间留一行空白及细分隔线。首页后续长度由保留内容决定，不设单页压缩目标。

概念布局：

```
英维克（002837.SZ）                                  公司介绍
行业：……                    法定代表人：……
主营业务：完整保留现有介绍，按内容占一至两行
──────────────────────────────────────────────────────────
估值概览                                           深墨绿标题
当前股价      目标价          潜在涨跌幅          估值区间
估值年份      模型 EPS        目标 PE             现有评级
次级行情信息（现有信息保留）

财务预测                                           中深绿标题
指标                  2025A │ 2026E     2027E     2028E
现有财务指标                 │
重点小计 / EPS               │          极浅绿结果行

关键经营假设                                       中深绿标题
现有年度假设矩阵

投资逻辑 / 未来展望 / 主要风险                      同级标题色

```

公司介绍区域和年度表使用各自适合的字段宽度，不因公司介绍的长文本而使某一个年度列特别宽。具体列安排在实施时结合下方既有文字区域确定，不能为了等宽年度列导致原有备注新增截断。

## 6. 科目与年度区域规范

优先利用现有行列结构，不进行全工作簿统一插行、插列。


| 区域      | 建议规则                                         |
| ------- | -------------------------------------------- |
| 科目列     | 收入、成本、利润表的科目列以 30—34 字符宽为参考，根据最长科目做适当调整      |
| 年度列     | 同一区域保持等宽，通常 12—14 字符宽；以两位小数、千分位及负数括号都能完整显示为准 |
| 历史/预测边界 | 2025A 与 2026E 之间加细竖线；历史表头近白绿，预测表头浅绿          |
| 标题/分区   | 同级标题使用相同字重、行高和色值；分区填充连续，不逐格加边框               |
| 单位      | 维持原单位列或行标签中的单位；共同单位在财务表标题附近简明列出              |
| 备注      | 保留原文、所在区域及展示方式；不新增备注列、来源编号或说明行               |


历史财务双栏、首页精选年度和同业列表按各自用途保留结构。首页重新安排字段时，既有研究文字仍保留在首页后续区域。共享列宽或区域移动必须避免给备注造成新增遮挡；若局部几何调整会迫使备注迁移，则优先采用不改变备注组织方式的布局。
