**总体判断**

现有项目已经具备可用的“分部收入预测 + 简化利润表 + PE 相对估值”框架。阶段 JSON、事实与预测分离、父子分部避免重复计入、量价单位显式化，都值得保留。

**二、预测思路应怎样调整**

建议把目前“材料 → 事件说明 → 拍量价 → 拍合并费率 → PE → 撰写理由”改为：

```text
统一估值日、披露日、业务范围、单位和会计口径
  → 历史及最新已实现数据、正常化利润
  → 暂定业务拆分，检查材料是否支持，再确定粒度
  → 行业需求 / 公司份额 / 产能 / 订单 / 价格的经营约束
  → 分部收入与分部盈利，共用事件和情景假设
  → 公司利润、现金与股本检查
  → 同期同口径共识差异归因，必要时回到前面修正
  → PE 主估值与辅助估值、上下行情景
  → 输出结果和可验证的研究观点
```

**事件必须通过可计算的中间变量进入预测。** 比如“匈牙利工厂投产”不足以直接支持动力销量 620GWh。至少需要可用产能、投产月份、爬坡利用率、合格率、已匹配订单与旧产能替代量；需求侧用行业需求与可比口径的公司份额形成独立约束。出货与收入确认若有差异，要显式加交付/验收桥接。年度实际销量、收入确认数量、装机量不能随意互换。

每条关键假设可以记录：指标、期间、基数、变化幅度、事件 ID、生效时间、计算关系、采用证据、替代解释、触发更新的条件。计算应由代码完成，模型负责选择有依据的参数并解释分歧。

**加一层最新已实现数据。** 财务取数只拉年度，2026 年 9 月仍从 2025 年末向前推三年。brief 中即便出现 2026Q1 或 H1，也没有硬约束全年预测。至少增加最新累计收入、利润、分部经营指标、剩余期间所需增速和季节性检查。例如“全年预测 − 已实现”得到下半年/剩余季度要求，再对照产能与订单。

**从收入走到毛利，而不止走到收入。** 同一个原材料价格变化应同时影响 ASP、单位成本、库存减值和传导时滞；同一个海外项目投产应同时影响可交付量、良率、固定成本摊销和费用。避免收入端先压价、毛利端再独立打折造成重复计入，也避免只计增量收入、不计爬坡成本。

**共识用来归因和挑战，不用于机械贴合。** 保留独立预测；但在定稿前用同日、同范围的预测比较，拆出分部销量、价格、结构、毛利、费用、财务与税项、股本的差异。现有流程在最后要求撰文解释分歧，却不允许改数，容易产生事后合理化。

**分清财务预测期与目标价期限。** 现在只用首年 EPS；后两年预测没有进入目标价公式，PE 选择阶段也没有使用最终两年盈利路径。内存敏感性显示，2028E 毛利率增加 5 个百分点，当前目标价完全不变。首年 PE 估值本身可成立，但应明确未来路径如何支持倍数，以及目标价是当前合理价格还是未来某时点价格。

| 正常化盈利     | 报告归母、扣非、补贴、投资收益、减值、汇兑、一次性税项；调整后的税及少数股东影响   | 确保 PE 乘的利润可持续；与同业使用相同基础       |
| 最新实际与季度桥接 | 年初至今实际、剩余季度要求、季节性、管理层指引                    | 避免全年数字脱离已经发生的经营结果             |
| 分部单位经济性   | 量、价、单位成本、毛利、产品/地区组合、产能和利用率                 | 支持收入与利润同步变化                   |
| 现金质量与再投资  | 经营现金流、资本开支、折旧摊销、应收/存货/应付周转、现金转化率           | 检查利润是否成为现金，以及增长需要多少投入；无需折现    |
| 财务和股本     | 有息债务、租赁负债、可用/受限现金、利率、非经营投资、分红、回购、增发、期权/可转债 | 支持财务费用、净现金、稀释 EPS 与每股价值       |

| 同业与自身历史   | 统一期间 PE、样本分布、增长/利润率/杠杆/回报率、历史分位、盈利修正趋势     | 判断 19.1 倍是否合理，以及参照组可能整体过贵或过便宜 |

当前“营运资本”是流动资产减流动负债，包含现金等项目；不能直接当作经营性营运资本来测算再投资需求。若增加现金分析，应另建经营性口径，避免现金和融资项目重复计入。

估值方法建议按用途选择：

- **正常化前瞻 PE 为主。** 先统一盈利基础与年份，再决定中位数、加权或均值，并明确调整逻辑。
- **自身历史估值区间作校验。** 同样使用历史当时可获得的盈利预测，避免拿事后实际盈利回填；历史业务结构改变时要降低旧倍数的参考权重。
- **EV/EBIT 或 EV/EBITDA 作辅助。** 前提是利润指标、租赁处理和企业价值到股权价值的桥接完整。EBITDA 不能替代资本开支与现金流分析。
- **SOTP 仅在业务差异实质且分部盈利可辨认时使用。** 有业务收入还不够；需要分部 EBIT/EBITDA 或其他合理分母。若分部按 EV 估值，再统一加非经营资产、扣债务和少数股东权益等，避免重复处理总部费用、联营投资、内部交易和现金。
- **P/B–ROE、资产净值等按行业补充。** 对银行、保险、地产等，不宜硬套现有工业企业的毛利/三费模板。缺盈利的企业应提供方法不可适用状态，而不是继续给负目标价。

若仍使用完整净利润乘 PE，不应再机械加回全部净现金；改做经营业务价值加净现金时，须同步剔除分母里对应的现金收益等，保证价值与盈利范围一致。

这些补充符合相对估值对盈利正常化、期间可比、基本面差异及企业价值倍数的要求。参考 [CFA：价格与企业价值倍数](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/market-based-valuation-price-enterprise-value-multiples)；同业可比性应考虑增长、风险和现金产生能力，参考 [Damodaran：Intrinsic vs Relative Value](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/littlebook/intrinsicvsrelative.htm)。上述模块配置是结合本项目的审核建议。

**五、实施顺序与验收**

第一批：修复缺失清零与比例猜测，处理空共识，补计算校验。预测利润口径仅补公式备注，可随文案完善一并处理，不涉及历史列、预测公式或假设项调整。验收是边界条件不再被误判为通过，历史事实不因驱动估计而改变。

第二批：统一资料时点，引入最新实际约束、分部毛利/单位成本、共识差异归因。验收是改变核心业务量、价、结构时，收入、成本和利润沿同一套假设传播，重要事件能落到可计算变量。

第三批：完善可比池（不默认剔除高倍数样本），补正常化盈利、现金/股本、情景与辅助估值。验收是每个目标价都有明确盈利基础、倍数依据、期限与风险范围。
