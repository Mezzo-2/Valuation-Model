## 1. 结论

**历史现金流主干可取得；实现可靠 DCF 还需补充经营/融资分类、附注明细、资本成本参数与未来再投资假设。** 当前缺项不能全部归因于数据平台不提供。

- 可直接增加采集：经营现金流 CFO、折旧摊销 D&A、资本开支候选；本轮 5 家公司、15 个公司财年均有数值。
- 可计算或从公告提取：历史 Beta、部分港股租赁与债务明细、研发资本化信息。需要新增计算与提取流程。
- 仍未解决：完整经营性营运资本 ONWC、可加回现金、有息债务及租赁的统一口径、ERP、估值日边际债务成本 Kd、长期税盾和现金税，以及未来 Capex、D&A、ONWC、增长及稳态 ROIC 假设。
- WACC 是 FCFF 口径 DCF 的折现率模块。建议保留 PE，增加“资本成本 + FCFF 预测 + DCF + 敏感性”，不将 WACC 作为第三个独立目标价。[CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

## 5. WACC 的实际可得性

采用基本关系：`Ke = Rf + Beta × ERP`；`WACC = Ke × E/(D+E) + Kd × (1−T税盾) × D/(D+E)`。如涉及国家风险溢价，应明确风险暴露与 ERP 定义，避免重复计入。

| 参数 | 本轮实际结果 | 后续数据动作 |
|---|---|---|
| Rf | 新宏观入口取得中美十年期国债收益率序列及来源；旧 indicatorNameRetrieve 返回“已下线” | 可接入新接口，但须处理日期与元数据冲突、估值时点和币种 |
| Beta | 财务专项查询 0 行，行情/快照也未直接返回；股票与基准历史序列可取 | 新增统一估计规则，或接入有定义的供应商 Beta；需要窗口、频率、基准、杠杆和调整方式 |
| ERP | 搜索“股权风险溢价”“股票风险溢价”均只返回世界银行“亚洲:中国香港:贷款的风险溢价” | 该项不是股权 ERP，不能替代；需另选权益风险溢价来源或估计方法 |
| Kd | 独立利息费用部分可取，港股可从公告拆出部分历史利息 | 补估值日债券到期收益率、信用利差或当前可融资利率；历史费用/平均债务只作辅助 |
| E、D 权重 | 行情市值、股数可取；债务与租赁覆盖不完整 | 用全部经济权益类别市值、同币种债务价值或说明过的近似值；确定目标资本结构 |
| T税盾 | 有会计所得税费用，但不能自动视作未来可实现的利息税盾 | 取得适用税率、税惠期限、亏损结转、递延税和利息抵扣限制 |

### Beta 已验证可以派生

实际调用 get_stock_kline（科大讯飞、前复权周线）和 searchIndexQuotation（沪深300、周线），固定区间 2024-11-01—2026-10-30。两边各 104 个同日收盘价，无错配日期；相邻共同日期构成 103 组收益率。

带截距的价格收益率回归得到历史 Beta **1.241326**，R² **0.240347**。这只是数据通路诊断，未作无风险超额收益调整，也未确定总回报基准、异常值、去杠杆/再杠杆及目标杠杆政策，**未作为最终 WACC 输入**。完整计算和逐期收益率见 beta_diagnostic.json、beta_return_pairs.json。

### Rf 已取到，但最新值不能直接上线

- 中国序列：名称“中债国债到期收益率:10年”，来源中国债券信息网。原始表出现 2026-11-03 的 1.621%，但同响应元数据截止日为 2026-10-30；请求起始月为 202610，响应仍包含更早月份。

## 6. 实现 DCF 仍需补充的清单

推荐 FCFF 主链：`经营EBIT − 经营现金税 + D&A − Capex − ΔONWC`。若用 `EBIT×(1−T)` 简化，T 必须代表适用的经营税负假设。CFO 用作核验；不能将所有市场的 CFO−Capex 或供应商“自由现金流”统一命名为 FCFF。[CFA Institute](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)

| 优先级 | 需要补的数据/政策 | 现有数据为什么不够 | 获取或形成方式 |
|---|---|---|---|
| P0 | 未来年度 Capex、D&A、经营营运资本预测 | 现有模型主要预测利润，利润不能替代现金流 | 接入历史序列，结合产能、研发、周转天数及资本开支计划形成预测 |
| P0 | 完整 ONWC 及其变动 | 当前“营运资本”=流动资产−流动负债，混有现金和融资项目 | 应收/票据、合同资产、存货、预付、经营其他资产，减经营应付、合同负债等；逐项分类 |
| P0 | 经营 EBIT 与正常化现金税 | 投资收益、补贴、融资净额、减值、调整后利润可能混入；科大讯飞历史税费为负 | 经营利润桥、当期/递延税拆分、优惠期限及亏损使用计划；避免把历史负税率永久化 |
| P0 | 股权价值桥 | 有息债务、租赁、受限现金、最低经营现金与非控股权益尚未齐备 | 补最新资产负债表及附注；区分非经营资产，防止与经营现金流重复估值 |
| P0 | WACC 完整参数 | ERP、边际 Kd、税盾和资本结构还未确定；Beta/Rf 通路需规范 | 增加市场参数采集、计算与来源日期校验 |
| P0 | 终值 g、稳态利润率和再投资/ROIC | 财务接口不会自动给出适用于本公司的长期估值假设 | 研究假设及情景；保证 WACC>g，增长与维持该增长的投入一致 |
| P1 | Capex 完整资产范围与资本化研发 | 港股候选仅“购买固定资产”；科大讯飞研发资本化金额未结构化 | 年报现金流明细、开发支出与无形资产附注；确认是否已包含在 Capex，避免重复扣除 |
| P1 | 租赁一致政策和非现金项目处理 | D&A 可能含使用权折旧，租赁本金列融资现金流；股份支付涉及稀释 | 将 EBIT、D&A、再投资、债务和股数统一；明确股份支付处理 |
| P1 | 估值日与现金流日期 | 模型预测首年部分已经发生，港美财年不同 | 最新 YTD、剩余期间预测、期末/年中折现规则及估值日桥接 |
| P1 | 多类别权益、交易单位和币种 | 谷歌快照 totalShare=58.88 亿股、floatShare=122.94 亿股，提示类别/汇总口径需核验；中芯有 A/H 两类市场价格 | 核对全公司经济股数、分股类价格、ADS 比例；折现率匹配现金流币种，最后再换交易币种 |

终值再投资必须与 g、稳态资本回报一致，不能同时假定正增长而无条件令 Capex 永远等于 D&A、营运资本投入为零。[Damodaran：终值与再投资](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/termvalueexreturns.htm)

**科大讯飞需要特别处理的两点：** FY2025 会计有效税率约为 -43.2%，不能直接用于长期 NOPAT 或 WACC 税盾；供应商“企业自由现金流量”为 17.1424 亿元，而 CFO−Capex 为 0.5746 亿元，二者公式和税/再投资口径未解释前，不能任选其一作为 FCFF。
